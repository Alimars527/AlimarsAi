### 3. @数据更新
- 触发词："@数据更新"、"数据更新"、"拉数据"、"同步数据"
- 含义：拉取并同步每日全市场行情数据（全5000+股票）
- 核心接口：
  - `pro.daily(trade_date=)` — 全市场日线，一次性返回约5500只股票
  - `pro.daily_basic(trade_date=)` — 全市场财务数据，同理一次性拉取
  - `pro.index_daily()` — 上证指数（最近35天）
- 执行内容：
  - 全市场日线数据（close/vol/amount/pct_chg 等）
  - 全市场日线财务数据（市值/PE/换手率等）
  - 上证指数日线
- 数据存放路径：
  - `data/index_daily/000001.SH.csv`
  - `data/daily/{ts_code}.csv`（每只股票一个文件）
  - `data/daily_basic/{ts_code}.csv`
- 脚本：`scripts/daily_data_sync.py`
- 性能：全市场约5500只股票，2-3分钟完成全量拉取
- 注意：ETF（如红利低波）无Tushare日线数据，属正常现象

### 4. @reset
- 备份进度到引导文件 + 重连

### 5. @候选票推荐
- 触发词："@候选票推荐"、"候选票"、"推荐股票"
- 含义：根据当前主线战法（B1战法 + 砖型图）进行全市场扫描，筛选出符合条件的候选股票
- 执行内容：
  1. 基于最新本地数据（data/daily/），对全市场进行B1信号和砖型图信号扫描
  2. 排除ST、北交所、V4行业黑名单（10个回避行业）
  3. 结合板块层级（T0/T1/T2）优先排序
  4. 生成候选票推荐表，追加到当日复盘文件末尾
- 输出格式（追加到 `reports/daily/YYYY-MM-DD_每日复盘.md`）：

| 标的 | 代码 | 所属板块 | 推荐买入成本 | 止盈 | 止损 | 建议购买量 | B1 | 砖型图 | 明日走势预测 |
|------|------|----------|-------------|------|------|-----------|-----|--------|-------------|
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

- 字段说明：
  - **标的**：股票简称
  - **代码**：ts_code（如 002594.SZ）
  - **所属板块**：所属行业板块
  - **推荐买入成本**：基于当前收盘价的合理买入价位
  - **止盈**：B1止盈（10%减半/20%全走）或砖型图止盈（8%）
  - **止损**：B1止损（黄线破位/10日弱势/高位转弱）或砖型图止损（次日不强/翻弱/失承接/-4%）
  - **建议购买量**：1-5手（结合用户仓位管理：50%红利低波，剩余给B1和砖型图）
  - **B1**：是否满足B1战法信号（✅/❌ + 简要说明）
  - **砖型图**：是否满足砖型图信号（✅/❌ + 蜡烛图形态标注，如看涨吞没、锤子线等）
  - **明日走势预测**：基于技术面的次日预判（偏多/中性/偏空 + 关键价位）

### 6. @创建复盘模板

- 含义：根据模板创建当日复盘空白文件

  - 在 `reports/daily/` 下创建 `YYYY-MM-DD_每日复盘.md`

### 7. @开始复盘
- 触发词："@开始复盘"、"开始复盘"、"做复盘"、"跑日报"、"生成日报"
- 含义：执行完整每日复盘流程，生成完整日报
- 执行步骤：
  1. 数据校验（确认本地CSV已有今日数据）
  2. 市场环境（OMAV + regime）
  3. 板块轮动（持仓日线 + stock_basic 合并 → 按行业聚合 → 平均涨幅 + 胜率）
  4. 热板块候选（`select_from_hot_sectors()`）
  5. 全市场扫描（B1/砖型图信号扫描）
  6. 过滤（`filter_for_next_day()` — ST/高位/北交）
  7. 持仓操作建议（支撑/压力/高开平开低开预案）
  8. 生成报告
- 输出文件：
  - `outputs/latest_plan.md`（最新完整日报）
  - `outputs/latest_summary.json`（结构化JSON）
  - `reports/daily/YYYY-MM-DD_每日复盘.md`（归档日报）
- 脚本：`scripts/run_daily_pipeline.py`
