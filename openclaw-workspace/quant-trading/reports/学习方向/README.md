## 学习规则

1. **从实战中来**：优先从用户交易中学习，而非纯理论
2. **好/坏/失效三分类**：每个样本必须标注好/坏/失效及原因
3. **持续积累**：不追求一次到位，每周至少新增1个样本
4. **用户反馈驱动**：用户纠正优先级最高，立即更新
5. **形态+量价+位置**：三个维度综合判断，不单看一个维度
