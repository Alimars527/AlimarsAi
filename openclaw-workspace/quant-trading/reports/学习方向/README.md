## 一、目的说明

该文档用于明确 Hermes 在本项目中的 A 股自主学习主线，避免后续学习发散、空转或偏离用户真实交易风格。

当前学习不是为了堆积知识，而是为了持续提升以下 5 项实战输出质量：
1. 收盘后复盘
2. 次日预案
3. 持仓分析
4. 候选股筛选与排序
5. 策略优化建议

## 二、用户交易画像（学习基准）

### 1. 交易风格
- 主短线趋势，次低吸波段
- 可接受约 1 个月持股周期
- 偏好少而精的持仓结构

### 2. 风险与收益偏好
- 更看重总收益
- 更怕回撤
- 可接受交易亏损结果，但不代表接受无纪律交易

### 3. 决策偏好
- 技术面优先，基本面辅助
- 重点关注：量能、K线走势、K线形状、图形结构
- 主要使用时点：收盘后复盘、次日预案

### 4. 约束条件
- 不碰 ST
- 少碰房地产行业
- 单票最大仓位不超过 50%

### 5. 当前学习优先级
1. 策略优化
2. 板块轮动
3. 环境判断
4. 候选排序

## 三、核心学习原则

### 原则 1：服务实战优先
所有学习必须最终反哺实战，不能只停留在概念理解或资料摘抄。

### 原则 2：以用户风格为主，不做泛化输出
Hermes 的学习重点应贴合“短线趋势 + 低吸波段 + 技术面主导”的实际风格，而非泛用型价值投资叙事。

### 原则 3：区分观察、统计发现、已验证增强项、正式规则
后续所有新认知统一分为：
- L1：观察
- L2：统计发现
- L3：已验证增强项
- L4：正式规则

### 原则 4：先优化主信号，再引入新因子
当前阶段优先学习与优化：
- B1 体系
- 严格砖型图 V3 / B2 相关技术图形理解
- 环境与板块对现有信号的适配关系

### 原则 5：先诊断，再改规则
任何新增观点必须优先回答：
- 它是现象还是规律？
- 它适合做硬过滤、排序加权、风险提示，还是仅保留为观察？

## 四、后续主要学习方向

### 学习方向 A：策略优化（第一优先级）

#### 目标
持续优化现有策略体系，尤其是 B1 与砖型图主线，不盲目扩展新战法。

#### 重点学习内容
- B1 V2 / V3 / V4-A / V4-B 的差异与适配环境
- 砖型图 V3 与 B2 类信号在不同环境下的表现差异
- 图形结构、量价结构与买点质量的关系
- 用户偏好的“图形好看”如何拆解为可讨论、可验证的结构语言

#### 计划输出
- 策略差异说明文档
- 关键增强项记录
- 失效场景归因记录
- 是否升级为正式规则的建议

### 学习方向 B：板块轮动（第二优先级）

#### 目标
提升板块轮动判断能力，增强对主线板块、轮动预期和补涨逻辑的识别。

#### 重点学习内容
- 主线板块的启动、分歧、回流、退潮结构
- 白酒、资源、半导体、新能源等轮动特征
- 板块轮动与个股信号成功率的关系
- 用户主观轮动判断与数据结果之间的偏差和一致性

#### 计划输出
- 板块轮动观察日志
- 主线/次主线判断记录
- 轮动有效性回顾
- 与候选排序联动的建议

### 学习方向 C：环境判断（第三优先级）

#### 目标
形成稳定的环境识别体系，判断何时应积极、谨慎或收缩。

#### 重点学习内容
- 活跃市值 / OMAV 与环境关系
- 市场风格切换对短线趋势和低吸波段的影响
- 弱势环境下策略失真特征
- 指数、情绪、成交变化与机会密度关系

#### 计划输出
- 环境标签体系
- 环境与策略适配说明
- 弱环境风险提示库

### 学习方向 D：候选排序（第四优先级）

#### 目标
在已有候选基础上，提升多标的同日比较能力。

#### 重点学习内容
- 图形结构优先级
- 量价质量优先级
- 板块背景对排序的修正作用
- 环境条件对排序的加减权逻辑

#### 计划输出
- 同日候选排序规则草案
- 排序案例记录
- 排序失误复盘

## 五、学习节奏安排

### 每日
- 接收用户持仓、操作、市场主观看法
- 同步当日环境值与关键上下文
- 记录新的市场观察与技术图形观察
- 复盘当日错误或值得跟踪的现象

### 每周
- 形成一份学习周报
- 总结新增认知、推翻旧认知、错误复盘
- 提出下周 1~2 个研究课题

### 每月
- 汇总本月有效认知
- 淘汰无效假设
- 判断哪些结论进入 L3 / L4
- 决定下月研究主线
