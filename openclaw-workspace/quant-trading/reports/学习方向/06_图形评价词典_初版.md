## 一、用途

该词典用于把用户对"好图形/坏图形/失效图形"的主观判断，转化为结构化、可复用、可解释的标准化语言。

核心目标：
1. 让 Hermes 在看到新图形时能对照词典做出结构化判断
2. 积累真实案例作为后续复盘和策略优化的证据
3. 为后续候选排序和图形质量过滤提供依据

## 二、好图形核心要素

### 2.1 整体节奏要求

| 要素 | 说明 | 用户偏好 |
|------|------|----------|
| 前期整理 | 信号前应有横盘或整理阶段 | 必须有，不能跳过 |
| 第一波启动 | 启动时量能逐步放大，但有节奏 | 允许放量，偏好有结构支撑的放量 |
| 回调质量 | 回调过程量能逐步衰减，结构温和 | 必须缩量，不能是失控杀跌 |
| 信号日结构 | 信号日K线不破坏白黄线关系 | 白线在黄线上，K线不破关键线 |

### 2.2 量价要求

| 状态 | 好图形 | 坏图形 |
|------|--------|--------|
| 上涨阶段 | 允许放量，甚至偏好放量启动 | 连续跳空、连续涨停、失控式放量 |
| 回调阶段 | 阴量递减、缩量整理、自然衰减 | 巨大阴量、量能无明显衰减 |
| 量价协调性 | 放量有因、缩量有理 | 放量无规律，量价节奏紊乱 |

### 2.3 线位关系

| 判断项 | 好图形 | 坏图形 |
|--------|--------|--------|
| 白黄线关系 | 白线始终在黄线上（重要强势背景） | 白线在黄线下，或白黄线混乱 |
| K线与关键线 | K线不能明显跌破白线、黄线 | K线跌穿白黄线，或在关键线下运行 |
| 信号日K线 | 信号日K线保持在关键线上方 | 信号日K线已破关键线 |

### 2.4 回调质量判断

好图形的回调：
- 回调要"弱中带稳"，不能是失控杀跌
- 更喜欢整理型回调，而不是破位型回调
- 回调过程中若失承接，图形质量会明显下降
- 白线不破是结构保持的重要标准

坏图形的回调：
- 回调阶段没有明显缩量
- 留下未补跳空空间
- 回调低点不断降低并落到白黄线下

## 三、坏图形核心特征

### 3.1 结构性坏图形

| 特征 | 描述 | 典型案例 |
|------|------|----------|
| 主升过热 | 连续跳空、连续涨停，走势失控 | 华东辽能 |
| 量价失控 | 放量毫无规律，量价节奏紊乱 | — |
| 回调不缩量 | 回调阶段量能没有明显递减 | — |
| 缺口未补 | 跳空空间未被充分回补，形成结构隐患 | — |

### 3.2 位置性坏图形

| 特征 | 描述 |
|------|------|
| 高位延伸 | 连续波段拉升很久（如从19拉到30），已处末段 |
| 缺乏整理 | 前期没有横盘整理，直接从高位出信号 |
| 空间不足 | 放大时间尺度后，已不具备新的启动空间 |

### 3.3 用户对坏图形的判断标准

即便B1信号出现、白线未破，若前序主升与回调质量很差，仍可定义为坏图形。

"没破白线"不是唯一标准，整体结构健康才是。

## 四、失效图形特征

### 4.1 局部窗口顺眼，放大后差

| 特征 | 描述 |
|------|------|
| 缩小窗口好看 | 短周期看图形不错 |
| 放大窗口已在高位 | 把观察窗口拉大后，已是连续波段上涨后段 |
| 缺乏整理基础 | 没有新的横盘整理，整理基础被用尽 |
| 空间不足 | 实际上不具备理想的再启动空间 |

### 4.2 裕同科技案例教训

- 前期稳步上涨，没有跳空，没有异常放量
- B1信号出现时K线也没跌破线
- 但放大看：从19拉升到30，已经连续波段上行很久
- 缺乏前期整理基础 → B1变成了高位延伸末段的假性好图

### 4.3 失效图形判断核心

图形局部顺眼，不代表大结构安全。
必须警惕"缩小窗口看很好，放大窗口看已在高位长趋势尾段"的情况。

## 五、术语定义

### 5.1 次日不强

- **定义**：买入次日未出红砖且股价走低
- **典型表现**：信号日后第二天没有继续上攻，反而小跌或横盘
- **常见误判点**：把正常的震荡整理误判为不强（需要区分整理和真弱）

### 5.2 失承接

- **定义**：回调低点不断降低并落到白黄线下
- **典型表现**：股价回调时，下跌的低点一个比一个低，且跌破白黄线支撑
- **常见误判点**：把正常的小幅回调当作失承接（需要看幅度和关键位置）

### 5.3 高位转弱

- **定义**：上涨中出现顶部十字星或阴量约为前一日红K量能3/4
- **典型表现**：连续上涨后在高位出现十字星、射击之星、或突然缩量阴线
- **常见误判点**：把上涨中途的正常整理当作高位转弱

## 八、使用说明

当看到新图形时，对照以下步骤判断：

1. **看节奏**：是否有前期整理 → 第一波启动 → 缩量回调 → 信号确认
2. **看量价**：上涨是否放量有节奏，回调是否缩量不失控
3. **看线位**：白线是否在黄线上，K线是否在关键线上
4. **看位置**：放大时间尺度后，是否已经连续波段上涨很久
5. **看跳空**：是否有未补跳空空间，是否有连续涨停失控

判断结论：
- 好图形：5项全满足或4项满足且无明显坏项
- 坏图形：有主升过热/量价失控/回调不缩量任一项
- 失效图形：局部窗口好但放大后已在高位且缺乏整理基础
