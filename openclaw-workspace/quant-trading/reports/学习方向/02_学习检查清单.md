# 学习检查清单

版本：V1.0
状态：启用中
最后更新：2026-04-10

## 一、用途

该清单用于检查 Hermes 当前阶段的学习是否真实发生、是否有闭环、是否有实战价值。

## 二、每日检查

### 必查项
- [ ] 是否记录了当日持仓变化
- [ ] 是否记录了当日市场主观看法
- [ ] 是否记录了至少 1 条市场或图形观察
- [ ] 是否标记了当日值得跟踪的风险点
- [ ] 是否把新的用户反馈纳入学习上下文

### 加分项
- [ ] 是否形成了当天的结构性新观察
- [ ] 是否对某个错误或疑点形成了待验证问题
- [ ] 是否把观察与已有策略联系起来

## 三、每周检查

### 学习质量检查
- [ ] 本周是否新增了认知
- [ ] 新认知是否做了 L1/L2/L3/L4 分级
- [ ] 新认知是否说明了证据来源
- [ ] 是否明确推翻或修正了旧认知
- [ ] 是否至少记录了 1 条关键错误
- [ ] 是否至少主动提出了 1 个研究课题

### 实战价值检查
- [ ] 是否影响了持仓分析
- [ ] 是否影响了次日预案
- [ ] 是否影响了候选排序
- [ ] 是否影响了风险提示

## 四、每月检查

### 系统性检查
- [ ] 是否形成了当月学习总结
- [ ] 是否淘汰了无效假设
- [ ] 是否有结论从 L1/L2 升级到 L3/L4
- [ ] 是否发现了新的重点研究方向
- [ ] 是否减少了重复犯错

### 文档化检查
- [ ] 是否更新核心学习文档
- [ ] 是否更新周报或索引型文档
- [ ] 是否把高频结论沉淀为可复用表达

## 五、警惕的假学习信号
- [ ] 只会总结，不会验证
- [ ] 只会提新点子，不会淘汰旧认知
- [ ] 只会说现象，不会分级
- [ ] 只会写文档，不会改善实战输出
- [ ] 只会讲道理，不会复盘错误

## 六、阶段通过标准

### 通过标准
- 每周都有新增认知或修正认知
- 每周都有错误复盘
- 每周都有主动研究问题
- 学习结果开始反馈到复盘或预案中

### 未通过标准
- 连续一周没有新增认知
- 连续一周没有错误复盘
- 连续一周没有主动研究问题
- 学习输出没有反哺任何实战内容

## 七、使用建议
- 每周至少按本清单检查一次
- 如连续两周未通过，应重新收缩学习方向，避免发散
- 如连续四周通过，可考虑升级下一阶段学习或迭代任务
