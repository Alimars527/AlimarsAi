## 使用原则
1. 每个版本一个文件，不混写。
2. 文件内固定写清楚：
   - 战法定位
   - 满足条件
   - 买入点
   - 卖出策略
   - 止盈
   - 止损
   - 当前状态（正式 / 候选 / 实验 / 已否决 / 🔒冻结）
3. 后续若再升级：
   - 新版本新增文件
   - 不直接覆盖旧版本文件
