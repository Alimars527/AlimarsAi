# 战法策略库

> 位置：`reports/战法策略库/`
> 目标：把当前项目里各战法版本的**条件定义、买入点、卖出策略、止盈止损**统一沉淀下来，便于复盘、接力和后续 AI/人工维护。

## 使用原则
1. 每个版本一个文件，不混写。
2. 文件内固定写清楚：
   - 战法定位
   - 满足条件
   - 买入点
   - 卖出策略
   - 止盈
   - 止损
   - 当前状态（正式 / 候选 / 实验 / 已否决 / 进行中）
3. 后续若再升级：
   - 新版本新增文件
   - 不直接覆盖旧版本文件
