# B1_V2 封板版

## 一、战法定位
- 类型：B1正式版
- 状态：历史正式版 / 已被 V3 替代
- 定位：右侧修复型短线战法

## 二、满足条件
### 基础硬条件（必须同时满足）
1. KDJ 的 J 值低于对应阈值
2. 总市值 > 100 亿
3. 白线 > 黄线
4. K线不完全在白线下

### J 值阈值
- 2023：`J < -10`
- 2024：`J < 0`
- 2025：`J < 18`
- 当前环境：`J < 25`

### 收束条件
1. 回调幅度 <= 15%
2. 回调时间 <= 15 天
3. 量能收束方式 B：回调后半段绿柱平均高度 < 前半段平均高度

### 行业排除
- 房地产
- 银行

## 三、买入点
- 主执行口径：`min(信号日收盘价 × 0.993, 次日开盘价 × 0.988)`
- 稳健备选：次日开盘买

## 四、卖出策略
- 主执行口径：固定持有 3 天
- 稳健备选：止盈 3% / 止损 3% / 最多持有 4 天

## 五、止盈
- 主执行口径：无单独分批止盈，按固定持有 3 天处理
- 稳健备选：+3%

## 六、止损
- 主执行口径：无单独硬止损，按固定持有 3 天处理
- 稳健备选：-3%

## 七、备注
- 该版本后续已被 B1_V3 取代，当前不作为主推荐正式版。
