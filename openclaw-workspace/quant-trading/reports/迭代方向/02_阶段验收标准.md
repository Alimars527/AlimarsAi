# 阶段验收标准

版本：V1.0
状态：启用中
最后更新：2026-04-10

## 一、用途

该文档用于判断 Hermes 在不同迭代阶段是否达标，避免“看起来很忙，但没有真正升级能力”。

## 二、第一阶段：画像对齐

### 验收条件
- [ ] 已明确用户交易风格
- [ ] 已明确用户风险偏好与仓位约束
- [ ] 已明确用户技术偏好
- [ ] 已记录当前持仓与买入原因
- [ ] 已明确后续最需要补充的信息项

### 达标表现
- 持仓分析开始贴近用户风格
- 不再给出明显偏离用户体系的泛化建议

## 三、第二阶段：策略体系对齐

### 验收条件
- [ ] 能说明 B1 各版本差异
- [ ] 能说明砖型图主线与相关信号的适用场景
- [ ] 能区分正式版、候选版、实验版
- [ ] 能区分本体优化与排序优化
- [ ] 能说明哪些结论已进入正式规则

### 达标表现
- 策略讨论开始变得稳定
- 不再混淆不同版本的定位

## 四、第三阶段：图形语言升级

### 验收条件
- [ ] 已建立第一批好图形案例
- [ ] 已建立第一批失效图形案例
- [ ] 已能更稳定描述量价与K线组合
- [ ] 已形成图形评价词典初版
- [ ] 已将部分图形语言用于持仓分析或预案

### 达标表现
- 对图形的解释更接近实战表达
- 用户更容易一眼看懂分析结论

## 五、第四阶段：轮动与环境联动

### 验收条件
- [ ] 能说明主线、次主线与补涨的差别
- [ ] 能说明板块轮动如何修正个股判断
- [ ] 能说明环境如何修正策略适配
- [ ] 已形成初步排序或加减权逻辑
- [ ] 已能识别“图形好但环境不支持”的风险

### 达标表现
- 次日预案更整体化
- 候选排序更少只看单票图形

## 六、第五阶段：错误纠偏与稳定输出

### 验收条件
- [ ] 每周至少有 1 条错误复盘
- [ ] 每周至少有 1 条主动研究课题
- [ ] 每周至少有 1 条新增或修正认知
- [ ] 学习周报已形成稳定输出节奏
- [ ] 学习结果已稳定反馈到复盘或预案

### 达标表现
- Hermes 开始具备可监督的自我进化能力
- 不再只是被动回答，而是主动学习、主动修正、主动反哺实战

## 七、总体验收标准
- [ ] 更贴近用户交易风格
- [ ] 更懂技术图形与量价结构
- [ ] 更能解释为什么买、为什么等、为什么卖
- [ ] 更能识别轮动和环境对个股的影响
- [ ] 更能把学习结果转成实际可用输出

## 八、使用建议
- 每完成一个阶段，可按本文件做一次正式验收
- 若连续两个阶段未达标，应回退检查前置阶段是否打牢
- 若已稳定通过前三阶段，可加速推进排序优化与系统化规则沉淀
