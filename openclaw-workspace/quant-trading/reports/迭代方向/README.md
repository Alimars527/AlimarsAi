## 治理规则

1. **小步迭代**：每个变更只改一个维度，可归因
2. **先验证再采纳**：新规则必须有回测支撑
3. **去劣存优**：历史战法的缺陷不能被继承
4. **用户确认**：策略参数变更前需用户确认
5. **BaseLine 不轻易动**：已定型策略是参照锚点
