## 一、目的说明

该文档用于明确 Hermes 在本项目中的后续迭代路径，即：
在已经确定学习主线后，下一步应该如何把学习结果逐步转化为更稳定、更可复用、更贴近用户风格的系统能力。

学习方向回答“学什么”，
迭代方向回答“学会以后怎么升级系统”。

## 二、迭代总目标

后续迭代目标不是新增更多概念，而是持续升级以下能力：
1. 对用户交易风格的贴合度
2. 对技术图形与量价结构的解释能力
3. 对策略失效与有效场景的归因能力
4. 对板块轮动与市场环境的联动判断能力
5. 对持仓分析与次日预案的实战可用性

## 三、迭代主线

### 迭代主线 A：用户画像迭代

#### 目标
让 Hermes 越来越懂“这个用户是怎么交易的”，而不是只会做泛泛市场分析。

#### 当前已知基础
- 主短线，次波段
- 技术面优先，基本面辅助
- 重视量能、K线、图形结构
- 偏好少而精
- 单票仓位上限 50%
- 回避 ST，少碰房地产
- 收盘后复盘与次日预案为主要使用场景

#### 后续迭代内容
- 补全止盈止损细则
- 补全用户对“好图形/坏图形”的判断样本
- 记录用户最满意和最不满意的交易案例
- 学习用户更偏好的买点、卖点和等待节奏

#### 预期效果
- 持仓分析更贴近用户真实审美与执行习惯
- 给出的建议更少“正确但不适用”

### 迭代主线 B：策略体系迭代

#### 目标
对现有策略做分层理解，形成“正式版 / 候选版 / 实验版”的稳定认知体系。

#### 后续迭代内容
- 明确 B1 V2 / V3 / V4-A / V4-B 的差异口径
- 明确砖型图 V3 与相关 B2 类图形在用户风格中的价值
- 区分哪些是本体优化，哪些只是排序增强
- 区分哪些可以进入正式规则，哪些只能作为辅助提示

#### 预期效果
- 策略讨论不再混乱
- 后续优化更有节奏，不会反复推翻基础框架

### 迭代主线 C：技术图形语言迭代

#### 目标
把用户的技术直觉逐步转化为 Hermes 可复用的结构语言。

#### 后续迭代内容
- 整理常见“好图形”案例
- 整理常见“失效图形”案例
- 学习量价、K线、位置、结构之间的组合判断
- 逐步建立“图形评价词典”

#### 预期效果
- Hermes 对图形的表达更加接近实战语言
- 后续候选排序和持仓判断更具画面感和可执行性

### 迭代主线 D：轮动与环境联动迭代

#### 目标
不只看个股图形，而是学会把板块与环境纳入判断体系。

#### 后续迭代内容
- 识别主线板块、补涨分支、轮动预期与退潮信号
- 研究不同环境下 B1 / 砖型图的适配度
- 学习“个股好看但环境不支持”的风险判断
- 学习“板块将轮但个股结构未到位”的等待逻辑

#### 预期效果
- 降低只看单票图形造成的误判
- 增强对次日预案的整体性判断

### 迭代主线 E：错误纠偏迭代

#### 目标
通过持续错误归因，减少重复犯错。

#### 后续迭代内容
- 每周至少记录 1 条关键错误
- 错误归类为：环境、板块、策略、排序、执行、数据理解
- 记录修正动作和后续验证结果

#### 预期效果
- Hermes 真正具备“自我修正能力”
- 学习不是只积累正确案例，而是能吸收失败样本

## 四、迭代阶段计划

### 阶段 1：画像对齐阶段

#### 目标
先让 Hermes 彻底理解用户交易风格、审美和约束。

#### 重点任务
- 记录用户当前持仓和买入逻辑
- 补全止盈止损规则
- 记录后续每笔交易结果反馈
- 归纳用户最看重的图形和量价特点

#### 阶段产出
- 用户交易画像增强版
- 常见买点/卖点判断样本

### 阶段 2：主线稳固阶段

#### 目标
围绕策略优化、板块轮动、环境判断建立稳定主线。

#### 重点任务
- 优先研究策略优化
- 结合板块轮动做策略适配判断
- 建立环境标签与谨慎/积极节奏建议
- 不急于扩展过多新资料和新因子

#### 阶段产出
- 主线策略学习周报
- 环境与策略适配说明
- 关键错误样本记录

### 阶段 3：系统升级阶段

#### 目标
把学习结果真正转化为系统能力，而不是零散认知。

#### 重点任务
- 将有效结论反馈到持仓分析
- 将有效结论反馈到次日预案
- 将排序逻辑写成相对稳定的说明文档
- 将用户认可的结论沉淀为规则库

#### 阶段产出
- 更稳定的复盘口径
- 更贴近用户风格的候选排序逻辑
- 可复用的规则说明文档

## 五、迭代验收标准

### 验收标准 1：贴合度提升
- 分析结果更接近用户实际操作思路
- 更少出现“方向没错但不适合用户”的建议

### 验收标准 2：解释力提升
- 能更清晰解释为什么买、为什么不买、为什么等、为什么减仓
- 能把用户的图形判断翻译成结构化语言

### 验收标准 3：稳定性提升
- 同类情境下判断逻辑更稳定
- 不再频繁切换分析口径

### 验收标准 4：反哺实战
- 持仓分析更实用
- 次日预案更具体
- 候选排序更有依据
- 风险提示更及时

### 验收标准 5：可监督
- 能按周报说明新增认知、错误复盘和研究方向
- 能说明哪些是观察，哪些已升级为规则

## 七、建议的固定输出

为保证迭代方向能持续推进，建议 Hermes 后续保持以下固定输出：
1. 学习周报
2. 错误复盘记录
3. 新认知分级记录
4. 次日预案中的策略适配说明
5. 对持仓个股的结构化评估

## 八、一句话总结
Hermes 的后续迭代，不是简单增加更多市场知识，而是持续升级对用户交易风格、策略体系、图形语言、轮动逻辑和错误归因的理解，最终把这些能力落实到更稳定、更贴合、更可执行的复盘与预案输出中。
