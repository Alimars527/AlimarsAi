# 迭代路线图

版本：V1.1
状态：正式推进中
最后更新：2026-04-12

## 一、目标

该路线图用于说明 Hermes 在当前项目中的能力升级顺序，确保迭代不是散点推进，而是按主次与阶段逐步增强。

## 二、迭代总路线

### 第一阶段：画像对齐
目标：先把用户交易风格、技术偏好、约束条件吃透。

重点任务：
1. 固化用户画像第一版
2. 补全止盈止损细则
3. 记录成功与失败交易样本
4. 理解用户对“图形好看”的审美表达

阶段产出：
- 用户画像增强版
- 图形偏好样本
- 初步止盈止损口径

### 第二阶段：策略体系对齐
目标：让 Hermes 真正理解当前策略体系，不混淆正式版、候选版、实验版。

重点任务：
1. 梳理 B1 V2 / V3 / V4-A / V4-B 差异
2. 梳理砖型图 V3 / B2 相关图形的适用场景
3. 区分本体优化与排序优化
4. 明确哪些是辅助提示，哪些是正式规则

阶段产出：
- 策略差异说明
- 正式版 / 候选版 / 实验版对照框架

### 第三阶段：图形语言升级
目标：把用户的技术图感逐渐转化为结构化语言。

重点任务：
1. 建立好图形案例库
2. 建立失效图形案例库
3. 梳理量价、位置、K线组合判断
4. 建立图形评价词典初版

阶段产出：
- 图形评价词典
- 图形案例样本库
- 图形判断统一表达

### 第四阶段：轮动与环境联动
目标：让个股判断不脱离板块和环境。

重点任务：
1. 研究主线、次主线、补涨与退潮
2. 建立轮动对候选排序的修正逻辑
3. 建立环境对策略适配的修正逻辑
4. 学会识别“个股好但环境不配合”的情况

阶段产出：
- 轮动观察框架
- 环境与策略适配模板
- 候选排序联动逻辑草案

### 第五阶段：错误纠偏与稳定输出
目标：让系统开始具备稳定学习闭环和自我修正能力。

重点任务：
1. 周度错误复盘
2. 周度认知升级或淘汰
3. 学习结果回流到持仓分析与次日预案
4. 稳定输出周报、验收和复盘文档

阶段产出：
- 错误样本库
- 稳定学习周报节奏
- 可追踪的认知升级记录

## 三、当前推荐推进顺序
1. 画像对齐
2. 策略体系对齐
3. 图形语言升级
4. 轮动与环境联动
5. 错误纠偏与稳定输出

## 四、当前阶段判定
- 当前所处阶段：第二阶段已完成，下一步正式进入第三阶段“图形语言升级”
- 当前重点：从策略版本梳理切换到图形样本沉淀、图形评价词典与结构化表达建设
- 当前不宜做的事：继续困在第二阶段里做零碎小过滤实验，或把未纯化的候选证据继续当成最终答案

## 五、阶段推进条件
- 当前已完成第二阶段中的候选双轨对照第一轮与稳健线口径纯化
- 当前可正式进入第三阶段“图形语言升级”
- 当成功/失败交易样本进一步累积并形成词典雏形后，可加速进入第四阶段
- 当周报与错误复盘稳定输出后，可加速进入第五阶段

## 六、一句话总结
当前迭代的正确顺序应是：先懂用户，再懂策略，再懂图形语言，再把板块和环境接进来，最后形成稳定的纠错与输出闭环。
