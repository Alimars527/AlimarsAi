# Obsidian 审阅稿目录

本目录用于存放**每日复盘成品文件**，供 Obsidian 审阅。

## 命名规范
- `YYYY-MM-DD_每日复盘.md`

例如：
- `2026-04-05_每日复盘.md`
- `2026-04-06_每日复盘.md`

## 使用规则
- 这里放的是**每日成品**，不是模板
- 模板文件仍放在：
  - `docs/phase/DAILY_REVIEW_TEMPLATE_V2_2026-04-05.md`
  - `docs/phase/DAILY_REVIEW_OUTPUT_FORMAT_V1_2026-04-05.md`
- 后续每日复盘优先输出到本目录

## 快捷指令（2026-04-09 新增）
以下口令为当前固定工作流，后续可直接在聊天中触发：

### @数据更新
- 含义：分段式拉取每日数据
- 要求：生成可视化 progress 文件；中断后优先续跑 / 尾段补跑；完成后删除临时 progress / state 文件

### @复盘
- 含义：开始当日复盘
- 要求：先看真实持仓，再看候选；最终只保留 `*_每日复盘.md`，不保留同日期无后缀重复文件

### @模拟实盘
- 含义：启动 / 延续独立 10w 仓模拟实盘
- 要求：
  - 先检查本地是否存在 `10w仓模拟实盘` 文件
  - 没有则新建，并按当前组合战法决定明日是否建仓
  - 有则基于之前买卖记录判断明日操作
  - 与真实持仓严格分离

### @历史回测
- 含义：按指定战法从 2023 至今回测
- 要求：
  - 先列出战法序号，等待用户回复选择
  - 回测脚本用分段式
  - 必须生成可视化进度文件
  - 输出胜率、盈亏及关键结果

### @活跃市值更新
- 含义：用户给一个数字，更新为今日活跃市值
- 要求：立即写入本地历史表与 latest 文件，并作为当日环境值使用

### @备份
- 含义：开始进行项目备份
- 要求：优先写入项目备份目录，按日期+主题命名

## 目标
将“规则文件”和“每日审阅稿”彻底分开，便于：
- Obsidian 按日期审阅
- 历史回看
- 日更维护
