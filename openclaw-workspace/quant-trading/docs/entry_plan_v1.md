## 一、B1 买入计划

### 信号特征
右侧动量反转 — J值低位回升(≤13) + 量能阳多阴少(57日>1.25或14日>2.25) + 白黄线附近(≥黄线×0.985)
本质: 底部蓄势后向上突破的起点

### 持仓周期与退出
- 最长持有: 10个交易日
- 止盈1: +10% 减仓一半
- 止盈2: +20% 全部清仓
- 止损: 黄线破位 / 10日弱势(收盘低于买入价×0.95) / 高位转弱(顶部十字星或阴量≈前日红K量3/4)

---

### Step 1: 信号日收盘后 — 计算买入区间

**输入(信号日数据):**
| 变量 | 含义 | 来源 |
|------|------|------|
| C | 信号日收盘价 | close |
| pct | 信号日涨跌幅(%) | pct_chg |
| vol_ratio | 量比 = 当日成交量 / 40日均量 | vol / vol.rolling(40).mean() |
| W | 白线(短期均线) | white_line |
| Y | 黄线(长期均线) | yellow_line |
| J | KDJ-J值 | kdj_j |
| prev1 | 前1日涨跌幅(%) | pct_chg[-1] |
| prev2 | 前2日涨跌幅(%) | pct_chg[-2] |

**① V4-A 过滤 (必检, 不过直接放弃):**
```
prev1 <= -1.0% AND prev2 <= -1.5% → 放弃
```

**② 窄修正过滤 (必检):**
```
白线明显压着收盘 (C/W < 0.96) AND 白黄线张口过大 (W/Y > 1.09) → 放弃
```

**③ 基础买入区间:**
```
下沿 = C × 0.985    (折1.5%)
上沿 = C × 0.993    (折0.7%)
追高线 = C × 1.010   (信号价以上1%绝对不追)
```

**④ 信号强度修正 (叠加在基础上):**

A) 涨幅修正:
```
pct >= 5%  → 下沿 = C×0.980, 上沿 = C×0.988  (大涨后等更深回踩)
pct 2~5%   → 保持基础区间
pct < 2%   → 下沿 = C×0.988, 上沿 = C×0.995  (温和信号,回踩浅)
```

B) 放量修正 (在A之后叠加):
```
vol_ratio >= 2.0 → 上沿 +0.005  (强势确认,可接受稍高价位)
```

C) J值修正 (在A+B之后叠加):
```
J <= 0 → 下沿 +0.005, 上沿 +0.005  (极端超卖,回踩可能很浅)
```

**⑤ 仓位决策:**
```
avg5 ∈ (1, 2] → 半仓 (50%资金)
其他情况       → 满仓 (正常仓位)
共振单(B1+砖) → 不做avg5降权,满仓
```

---

### Step 2: 次日 9:25 — 集合竞价后调整

以集合竞价确定的 open_price 判断场景:

**场景A: 高开 ≥ 2% (open ≥ C × 1.02)**
```
→ 进入观望模式
→ 盘中回落到追高线(C×1.01)以下才考虑
→ 回落到基础区间下沿 → 优先买入
→ 10:30仍未回落 → 放弃,不追
```

**场景B: 平开 -1.5% ~ +1.5%**
```
→ 正常执行买入区间
→ 9:30 挂限价单在下沿
→ 10:00 未成交 → 上调至上沿重新挂单
→ 10:30 仍未成交 → 放弃当天
```

**场景C: 低开 < -1.5%**
```
→ 优质机会(给了更好价格)
→ 扩大区间: 下沿 = C×0.978, 上沿 = C×0.985
→ 开盘后观察15分钟:
  - 低点企稳(不再下移) → 买入
  - 继续放量杀跌 → 放弃(信号可能失败)
```

---

### Step 3: 盘中执行规则

```
挂单窗口:  9:25 ~ 10:30
10:30后:   不新开仓
手续费预估: 买入价×股数×万0.86 (最低5元)
保本卖出价: 买入价 × 1.0067 (覆盖双向费用约0.67%)
```

## 二、砖型图买入计划

### 信号特征
趋势回踩反转 — 上升趋势(白>黄, high≥白)中, 砖型图由连续绿(≥4天)翻红
本质: 在已确认的上升趋势中,抓住短期回踩结束的转折点

### 持仓周期与退出
- 持有: 1个交易日 (T+1)
- 次日收盘卖出
- 止盈: +8%
- 止损: 次日不强(未出红砖且走低) / 翻弱(砖翻绿) / 失承接(低点降低并破白黄线) / -4%

---

### Step 1: 信号日收盘后 — 计算买入区间

**输入:**
| 变量 | 含义 | 来源 |
|------|------|------|
| C | 信号日收盘价 | close |
| pct | 信号日涨跌幅(%) | pct_chg |
| green_streak | 翻红前的连续绿砖天数 | brick_formula_green 回溯 |
| brick_val | 翻红日砖值 | brick_formula_value |
| W | 白线 | white_line |
| Y | 黄线 | yellow_line |

**① Rotation确认 (必检):**
```
所属板块必须在 Rotation Top5 → 否则放弃
```

**② 基础买入区间:**
```
下沿 = C × 0.980    (折2.0%)
上沿 = C × 0.990    (折1.0%)
追高线 = C × 1.005   (信号价以上0.5%不追, T+1对入场价极度敏感)
```

**③ 信号强度修正:**

A) 绿砖连天数:
```
>= 6天 → 下沿+0.003, 上沿+0.003  (长连绿后翻红,信号极强,回踩浅)
4~5天 → 保持基础区间
```

B) 翻红日涨跌幅:
```
pct >= 3% → 上沿+0.005   (翻红日强势,次日有惯性)
pct < 0%  → 下沿-0.005   (翻红但股价仍跌,需要更深回踩确认)
```

C) 白黄线间距(趋势强度):
```
W/Y > 1.05 → 下沿+0.003  (趋势强,回踩大概率浅)
W/Y < 1.02 → 区间收窄为 [C×0.978, C×0.985]  (趋势弱,谨慎)
```

---

### Step 2: 次日开盘应对

**场景A: 高开 ≥ 2%**
```
→ 危险！砖型图是回踩反转,高开说明反转已跑了一段
→ 只有盘中回落到上沿(C×0.99)以下才考虑
→ 10:00前未回落 → 放弃
→ 砖型图T+1,追高=自杀,绝不在追高线以上买入
```

**场景B: 平开 -1.5% ~ +1.5%**
```
→ 正常执行
→ 9:30 挂限价单在下沿
→ 9:45 未成交 → 上调到区间中位
→ 10:00 未成交 → 上调到上沿
→ 10:15 未成交 → 放弃 (T+1不将就)
```

**场景C: 低开 < -1.5%**
```
→ 最佳场景(这就是你在等的回踩！)
→ 扩大区间: 下沿 = C×0.973, 上沿 = C×0.985
→ 开盘后10分钟观察:
  - 低点企稳 → 果断买入
  - 放量下杀 → 放弃(不是回踩,是反转失败)
```

---

### Step 3: 盘中执行规则

```
挂单窗口:  9:25 ~ 10:15 (比B1短! T+1必须果断)
10:15后:   不新开仓
关键原则:  砖型图T+1, 入场价决定生死, 宁可错过不追高
次日提醒:  止盈=买入价×1.08, 止损=买入价×0.96 或 次日开盘不强
```

## 三、共振买入计划

### 信号特征
B1 + 砖型图 同日触发 — 底部动量反转 + 趋势回踩反转 共振
本质: 两个独立系统同时确认, 概率最高的事件

### 持仓周期与退出
- 持有: 1个交易日 (T+1)
- 次日收盘卖出
- 止盈: +10% (共振信号放宽止盈)
- 止损: 次日不强 / -4%

---

### Step 1: 信号日收盘后 — 计算买入区间

**输入:** B1全套 + 砖型图全套

**① V4-A + 窄修正 (同B1):**
```
prev1 <= -1% AND prev2 <= -1.5% → 放弃
C/W < 0.96 AND W/Y > 1.09 → 放弃
```

**② 基础买入区间 (三套中最宽松):**
```
下沿 = C × 0.988    (折1.2%)
上沿 = C × 0.995    (折0.5%)
追高线 = C × 1.015   (可追到信号价以上1.5%, 仅共振有此待遇)
```

**③ 信号强度修正:**

A) 涨幅修正:
```
pct >= 5% → 下沿=C×0.983, 上沿=C×0.990  (大涨后等回踩)
pct < 2% → 下沿=C×0.990, 上沿=C×0.997   (温和,回踩浅)
```

B) 双信号叠加:
```
J <= 0 AND green_streak >= 6 → 下沿+0.005, 上沿+0.005  (极强共振)
vol_ratio >= 2.0 → 上沿+0.005
```

**④ 仓位:**
```
共振单不做 avg5 降权 → 满仓
```

---

### Step 2: 次日开盘应对

**场景A: 高开 1.5% ~ 3%**
```
→ 共振可以容忍适度高开
→ 区间调整: [open×0.993, open×0.998]
→ 盘中回落到区间内 → 买入
```

**高开 > 3%**
```
→ 回到保守: 只有回落到 C×0.995 以下才考虑
```

**场景B: 平开 -1.5% ~ +1.5%**
```
→ 正常执行基础区间
→ 9:30 挂限价单在下沿
→ 9:45 未成交 → 上沿
→ 10:00 未成交 → 可在追高线(C×1.015)以内买入 (共振特权)
```

**场景C: 低开 < -1.5%**
```
→ 天赐良机,不要犹豫
→ 扩大区间: 下沿 = C×0.980, 上沿 = C×0.988
→ 开盘企稳即买入
```

---

### Step 3: 盘中执行规则

```
挂单窗口:  9:25 ~ 10:30
共振特权:  可在追高线以内买入(仅共振有此特权)
次日提醒:  止盈=买入价×1.10, 止损=买入价×0.96
```

## 四、通用规则

### 1. OMAV 环境过滤
```
熊市(bear_regime=True)  → 全部不开仓
预警(warning=True)       → 仅做共振单,最多1个仓位
正常                      → 三套都可用,最多3个仓位
```

### 2. 排序优先级
```
共振 > 砖型图 > B1
同类型内: J值升序(J越低越优先)
```

### 3. 仓位管理
```
红利低波: 独立仓位(目标50%), 不影响B1/砖型图资金
单票上限: ≤ 50%可用资金
B1降权:   avg5∈(1,2] → 50%仓位
共振:     不降权,满仓
```

### 4. 手续费
```
佣金: 万0.86 (最低5元/笔)
印花税: 万5 (仅卖出)
保本卖出价 ≈ 买入价 × 1.0067
```

### 5. 板块优先级
```
T0: AI算力/半导体/芯片/AIDC/人工智能/IT设备/通信设备/软件服务/互联网
T1: 光伏/储能/新能源/电气仪表/化工原料/化肥农药
T2: 有色/通信/电力/矿物制品/新材料
回避: 特高压/电力/商业航空/有色(不含新材料)
```
