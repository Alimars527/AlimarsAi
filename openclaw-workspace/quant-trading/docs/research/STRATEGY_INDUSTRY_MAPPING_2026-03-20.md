# 行业 -> 优先策略映射（截至 2026-03-20）

基于当前第二阶段回测结果的阶段性结论：

## 一、主线趋势优先
### 1. 元器件
- 长样本分组复核下，原始信号层表现相对更优。
- 更适合趋势延续逻辑。
- 执行上更偏平开承接，避免高开追。

### 2. 电气设备
- 长样本分组复核下，原始信号层整体优于医药方向。
- 更适合趋势跟随类策略。

### 3. 软件服务（次一级）
- 可纳入主线趋势，但内部票性分化明显。
- 后续需继续拆分“高弹性主线 / 稳定趋势主线 / 边缘趋势”。

## 二、轮动补涨优先
### 1. 医药商业
- 在主线趋势框架下整体并不优秀。
- 在“轮动补涨 + 纪律化卖点”框架下，结果明显改善。
- 更适合短打、兑现就走。

### 2. 化学制药
- 与医药商业类似。
- 不适合粗暴主线趋势持有。
- 更适合轮动补涨 + 卖点纪律。

## 三、当前阶段总结
- 不是所有偏好行业都适合同一套策略。
- 当前研究已经可以初步形成：
  - 元器件 -> 主线趋势优先
  - 电气设备 -> 主线趋势优先
  - 软件服务 -> 主线趋势次优先
  - 医药商业 -> 轮动补涨优先
  - 化学制药 -> 轮动补涨优先

## 四、注意
这仍然是第二阶段中的阶段性映射，不是最终定论。
后续还需：
1. 更长样本复核
2. 票性分层
3. 更细的买点/卖点模型验证
