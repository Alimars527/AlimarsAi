## 四、建议购买量规则（当前默认）

候选标的建议购买量，需要结合以下信息：

### 已知输入
- 仓内资金总额（当前你给出的例子：`44144.41`）
- 当前各持仓买入手数
- 当前收盘价 / 预计购入成本
- 当前剩余现金
- 当前总仓位
- 市场环境强弱

### 建议输出
每个候选标的至少给出：
- 建议买入：几手
- 预计投入：多少元
- 建议理由：
  - 轻仓试错
  - 标准仓位
  - 观察为主，不建议出手

### 原则
1. 弱环境 / 转弱环境：建议购买量从严
2. 多策略共振标的：可适度提高建议仓位
3. 单标的仓位不宜过大，避免集中暴露
4. 购买量必须结合剩余现金与已有持仓占比
5. 若现金不足或风险收益比不合适，应明确写：**不建议购买**

- 名称 / 代码 / 行业 / 预计购入成本 / 建议购买量 / 预计投入金额 / 止盈止损 / B1_V3 / 砖型图V3 / Top5 / 明日走势预测 / 操作备注

## 六、一句话标准
后续每日复盘不仅要回答“买什么 / 持有什么”，还要回答：

**现在仓位如何、还能买多少、为什么这样配。**
