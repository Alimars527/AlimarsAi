# Phase 3 Entry Plan — 2026-03-22

## Phase 3 核心目标
将 Phase 2 的正式版候选结构，从研究系统推进到可持续使用的执行验证系统。

## 三个核心任务
1. 纸上实盘 / 小资金实盘验证
2. 记录系统输出与实际执行偏差
3. 收敛为真正可长期使用的策略版本

## 建议执行方式
- 每个交易日保存系统输出候选清单
- 记录：是否执行、执行理由、实际结果、偏差原因
- 每周做一次“系统输出 vs 实际执行”复盘

## 进入条件
- Phase 2 正式版结构已固定
- 多因子分层（hkhold / margin / moneyflow / 二次确认）已明确
- 当前不再继续无边界扩因子
