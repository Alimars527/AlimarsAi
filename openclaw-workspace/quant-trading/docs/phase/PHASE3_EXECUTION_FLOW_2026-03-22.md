# Phase 3 Execution Flow

## 每日流程
1. 收盘后运行系统，生成 latest_plan.md / latest_summary.json
2. 从重点候选中记录：
   - 标签
   - 二次确认层级
   - 建议区间
3. 次日结合盘面决定是否执行
4. 收盘后记录实际结果与偏差原因

## 每周流程
1. 汇总本周系统输出与实际执行
2. 比较：
   - strong_confirm 组表现
   - assist_confirm 组表现
   - front_only 是否应继续降权
3. 复盘系统与执行之间的偏差
4. 决定是否需要进入小幅规则微调

## 核心原则
- 先记录，再优化
- 不因为一两笔波动随意改规则
- 先看 20~40 个交易日连续验证结果
