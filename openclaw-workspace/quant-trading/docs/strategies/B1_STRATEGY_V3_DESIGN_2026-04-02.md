# B1 战法 V3 设计稿（2026-04-02）

## 目标
在 B1 战法 V2 基础上，不再依赖板块轮动、砖型图共振、周日共振等外部叠加，而是只围绕 B1 本体做结构纯化。

## V2 保留内容
- 右侧战法
- 动态 J 阈值
- 总市值 > 100 亿
- 白线 > 黄线
- K线不完全在白线下
- 房地产、银行剔除
- OMAV 作为权重/频率层，不作为硬过滤
- 回调幅度 <= 15%
- 回调时间 <= 15 天
- 量能收束采用方式B：回调后半段绿柱平均高度 < 前半段平均高度

## V3 第一轮研究方向
### 方向A：前涨质量
目的：排除“没有真正上攻、只是弱反抽/横盘波动后的小回踩”样本。

第一版程序化口径（待验证）：
- 信号日前 10 个交易日内，出现过一段有效上涨
- 用简化表达：从近 10 日最低收盘到回调起点（局部峰值）涨幅 >= 8%

### 方向B：末端承接
目的：排除“回调还没结束、只是过程中短暂触发”的样本。

第一版程序化口径（待验证）：
- B1 信号日前 3 个交易日内，不再创新低
- 且最近 2 个交易日收盘重心抬高（close[t] >= close[t-1]）或至少当前收盘 >= 前一日收盘

## 回测拆分顺序
1. B1 V2 + 前涨质量
2. B1 V2 + 末端承接
3. B1 V2 + 前涨质量 + 末端承接

## 备注
这只是 V3 的第一轮研究口径，不代表最终定版。核心目标是验证哪一条本体结构收束真正有效，而不是继续靠外部标签硬压频率。
