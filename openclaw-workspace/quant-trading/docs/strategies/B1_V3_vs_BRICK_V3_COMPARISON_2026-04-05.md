# B1战法 V3 vs 砖型图 V3 对照表（2026-04-05）

## 一、定位对比

### B1战法 V3
- 类型：右侧修复战法
- 来源：B1 V2 经 Task B 条件拆解与第二轮精简复核后形成的新候选版本
- 核心思路：保留基础硬条件，删除无效约束，提升整体收益质量

### 砖型图 V3
- 类型：超短结构战法
- 来源：优质砖型图 V1 + OMAV 硬过滤 + 板块轮动 Top5
- 核心思路：在砖型图本体基础上做环境与轮动收缩，聚焦高质量信号

---

## 二、策略条件对比

### B1战法 V3 条件
#### 基础硬条件
1. `J < 年度/环境阈值`
2. `total_mv > 100亿`
3. `white_line > yellow_line`
4. `K线不完全在白线下`

#### 收束条件
5. `回调时间 <= 15天`
6. `量能收束方式B`
   - 回调后半段绿柱平均高度 < 前半段平均高度

#### 明确删除
- 删除：`回调幅度 <= 15%`

---

### 砖型图 V3 条件
#### 本体条件
1. `XG = 1`（前一日绿砖，当日红砖）
2. 当日 K 线不能完全在白线下方
3. 当日红砖前的前 4 个交易日均为绿砖
4. 前 4 个绿砖体积连续变小
5. 当日红砖体积 >= 前一日绿砖体积
6. 白线在黄线上

#### OMAV 环境过滤
满足任一：
- 单日 `OMAV >= 4`
- 连续两日 `OMAV 相加 >= 4`

过滤掉：
- 单日 `OMAV <= -2.3`
- 连续 5 日 `OMAV 合计 < -5`

#### 轮动过滤
- 只保留当日行业涨幅排名前 5 的板块
- 即：`rotation rank <= 5`
