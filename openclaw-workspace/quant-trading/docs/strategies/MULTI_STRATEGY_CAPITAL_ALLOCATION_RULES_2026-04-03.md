# 多策略同日冲突下的资金分配规则（2026-04-03）

## 一、适用场景
当同一交易日内，同时出现：
- B1 战法 V2 标的
- 砖型图 V1 标的
- 砖型图 V3 标的
且可用资金有限（例如 5w）时，用本规则做优先级排序和仓位分配。

## 二、核心原则
1. **宁可少做，不要摊太薄**
2. **信号层级优先于信号数量**
3. **重复上榜 / 多策略重合优先**
4. **V3 高于 V1，正式版本高于基础版本**
5. **弱环境下降低出手数量，不因信号多而强行出手**

## 三、信号优先级排序
### 第一优先级
- **B1 战法 V2 + 砖型图（同日重复上榜）**
- 这类标的优先进入核心观察池

### 第二优先级
- **砖型图 V3**
- 因为 V3 已是当前砖型图正式高版本

### 第三优先级
- **纯 B1 战法 V2**
- 当前命中率较高，但频率也较高，因此在有限资金下不优先于重复上榜与 V3

### 第四优先级
- **纯砖型图 V1**
- 胜率不如 V3，只作为补充观察，不作为优先出手对象

## 四、同层内部排序原则
在同一层级内部，再看以下因素：
1. 所属行业当天是否偏强
2. 价格位置是否别扭（是否过高、是否追价）
3. 次日是否容易给合理买点
4. 是否过于拥挤或处于不舒服位置

## 五、仓位分配规则（以 5w 为例）
### 正常环境
- **最多做 2~3 只**
- 做 2 只：每只约 2w~2.5w
- 做 3 只：每只约 1.5w~1.7w
- 保留少量现金机动

### 转弱环境
- **最多做 1~2 只**
- 优先只看：
  - 重复上榜标的
  - 或 V3 标的
- 纯 B1 / 纯 V1 尽量后置

### 明显差环境
- **允许空仓 / 不交易**
- 不因为当天出现很多信号就机械开仓

## 六、示例
若同日出现：
- A、B、C、D 满足砖型图 V1
- E、F 满足砖型图 V3
- A、B、G、H、I 满足 B1 战法 V2

则优先级应为：
1. **A、B**（重复上榜）
2. **E、F**（砖型图 V3）
3. **G、H、I**（纯 B1）
4. **C、D**（纯砖型图 V1）

### 若资金仅有 5w：
- 正常环境：优先从 **A、B** 选 2 只，再看 **E/F** 是否补 1 只
- 转弱环境：优先只做 **A/B** 中最强的 1~2 只，或改看 **E/F**，其余放观察池

## 七、当前认知总结
- 资金有限时，关键不是“信号有多少”，而是“先做哪一层”
- 正式版本、重复上榜、强确认，应优先于高频广撒网版本
- 环境差时，出手数量应缩，不应因信号数量增多而加仓扩张
