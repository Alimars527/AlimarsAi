## 二、信号源

### 2.1 B1 (b1_experimental_ok)

**7条件全过 + 2均线条件**

1. **J_OK** — KDJ的J值 ≤ 13（阈值按年调整：2023→-10, 2024→0, 2025→18, 2026→25）
2. **MVOK** — 总市值 ≥ 50亿
3. **GOOD28** — 近21天无"高位放量阴线"（open在21日高位85%分位 + 收阴 + 量>前日1.2倍）
4. **PLRY_CNT** — 放量阳线（量>前日1.95倍+收阳+量>40日均量）：近14天≥2次 或 近57天≥4次
5. **THREE_SUM** — 近57天"放量阳首现+连续放量阳+缩量半跌"合计≥4次
6. **MAX28_OK** — 近28天最大成交量那天不是阴线
7. **阳阴比** — （57日阳量>1.25倍阴量 且 14日阳量>2.25倍阴量）或 只需14日阳量>2.25倍阴量

**均线附加：** 白线 ≥ 黄线×0.985 + 收盘价 ≥ 黄线×0.985

### 2.2 砖型图 (BRICK_V3)

- brick_raw_turn_red = True（当天翻红）
- brick_history_ok = True
- **板块轮动Top5** — 所属行业在当天全市场行业涨幅排名前5
- 最高价 ≥ 白线，白线 > 黄线
- 前4天全绿砖 + 砖型值前4天递减 + 当天回升（z[idx] ≥ z[idx-1]）

### 2.3 共振 = B1 + 砖型图同时满足

**优先级：** 共振(0) > 砖型图(1) > B1(2)  
**同类型排序：** J值从小到大（J越低越超卖，排名越靠前）  
**候选数：** 取前 can_open × 2 只

## 三、仓位约束规则（三层）

### 第一层：OMAV仓位上限（实盘改为纯风控提醒，不强制限仓）

| OMAV状态 | bear(熊市) | warn(警告) | 正常 |
|---|---|---|---|
| 每日新开上限(max_new) | 0 | 1 | 3 |
| 总持仓上限(max_total_pos) | 0 | 1 | 3 |

> 回测验证：有OMAV强制限仓 +172.93%/591笔/49.92%WR/-18.33%DD，无OMAV +219.99%/585笔/50.6%WR/-16.16%DD。OMAV强制限仓拖累收益，实盘改为纯风控提醒。

### 第二层：可用槽位计算

```
free_slots = max(0, max_total_pos - 当前持仓数)
can_open = min(max_new, free_slots)
```
→ can_open=0 则当天不开任何新仓，即使有信号触发。

### 第三层：信号排序 + 截断

1. 排序优先级：共振(B1+砖型图)=0 > 纯砖型图=1 > 纯B1=2
2. 同级别内按KDJ-J值从小到大排
3. 排序后只取前 can_open×2 只进入买卖流程
4. 逐只尝试，需通过：低吸成交判断 + 前两日结构过滤 + 资金够不够
5. opened达到can_open即停止

**⚠️ 关键结论：** BaseLine不是有信号就全买，而是受仓位上限约束，从排序后的候选里依次买入直到开满。

## 四、买入规则

- 买入价 = min(信号日收盘×0.993, 次日开盘×0.988)  
  【砖型图用 0.995/0.99】
- 次日最低价 ≤ 买入价才成交
- 纯B1需过"前两日过滤"：前两天连续跌>1.5%则跳过
- 等权开仓（budget = cash / slots_left），avg5∈(1,2]时B1降权50%

## 五、退出规则

### 砖型图 / 共振
- 持1天，次日收盘卖出（固定）

### B1
- **TP1：** +10% → 卖半仓，设回撤止损线 = TP1当天最低价×0.93
- **TP2：** +20% → 全卖
- **回撤止损：** TP1后收盘 ≤ 回撤止损线 → 全卖
- **黄线止损：** 收盘跌破黄线 → 全卖
- **最大持有10天：** 到期收盘全卖

## 八、执行层调整（算法冻结后唯一允许修改的层面）

### 8.1 蜡烛图二次确认规则

规则文件：`docs/蜡烛图二次确认规则_V1.md`

在候选票扫描完成后、下单前，对每只候选票执行：

1. **拉取近10日K线**，标注每日阴阳和形态
2. **逐条检查排除条件**：
   - E1 急跌中（5日内跌停或单日-7%以上）→ 不买
   - E2 看跌吞没后（未收复）→ 不买
   - E3 高位射击之星/墓碑十字后 → 不买
3. **检查降权条件**：
   - D1 止跌信号未确认 → 观察仓
   - D2 低位横盘缩量 → 观察仓
   - D3 弱反弹（<38.2%回撤位）→ 观察仓
4. **检查加分条件**：
   - B1 锤子线+确认阳线 → 正常买入
   - B2 看涨吞没 → 正常买入
   - B3 启明星 → 正常买入
   - B4 突破缺口不回补 → 正常买入
5. **无信号干扰** → 按BaseLine原信号正常买入

### 8.2 已知Bug

- 无去重检查：同一只股票可被重复买入（如600726在4/16和4/17各买一次）
