# B1战法 V3（2026-04-05 定稿草案）

## 一、战法定位
- **B1战法 V3** 是在 **B1战法 V2** 基础上，经 Task B 条件拆解与第二轮精简复核后得到的新候选版本。
- 目标不是扩大频率，而是在保持右侧修复思路不变的前提下，修正 V2 中的无效约束，提升整体收益质量。

## 二、V3 核心结论
Task B 两轮结果确认：
1. **删除 `回调幅度 <= 15%`** 是正优化。
2. **保留 `回调时间 <= 15天`** 是正优化。
3. **保留 `量能收束方式B`** 是正优化。
4. **`K线不完全在白线下`** 仍是关键质量护栏，必须保留。

## 三、V3 当前建议条件
### 1）基础硬条件（保留）
1. `J < 年度/环境阈值`
2. `total_mv > 100亿`
3. `white_line > yellow_line`
4. `K线不完全在白线下`

### 2）收束条件（V3保留）
1. **回调时间 <= 15天**
2. **量能收束方式B**
   - 回调后半段绿柱平均高度 < 前半段平均高度

### 3）从 V2 删除的条件
1. **删除：回调幅度 <= 15%**

## 四、与 B1战法 V2 的差异
### V2
- 基础硬条件
- 回调幅度 <= 15%
- 回调时间 <= 15天
- 量能收束方式B

### V3
- 基础硬条件
- **删除 回调幅度 <= 15%**
- 保留 回调时间 <= 15天
- 保留 量能收束方式B

## 五、删除“回调幅度<=15%”的原因
Task B 第一轮与第二轮都显示：
- 删除该条件后，事件数增加
- 胜率不降反升或基本持平
- 平均收益提升
- 中位数提升
- trimmed mean 也提升

### 关键对比
#### B1_V2_BASE
- event_count = 10540
- win_rate = 51.31
- avg_return = 0.3213
- median = 0.1101
- trimmed_mean_10 = 0.1254
- trimmed_mean_20 = 0.0945

#### B1_BASE_NEW_PLUS_DAYS_VOLUME（V3候选）
- event_count = 12266
- win_rate = 51.39
- avg_return = 0.3830
- median = 0.1282
- trimmed_mean_10 = 0.1598
- trimmed_mean_20 = 0.1200

结论：
- `回调幅度<=15%` 没有承担有效提纯作用
- 它更像是**不必要地砍掉了一部分原本有效样本**

## 六、为什么保留“回调时间<=15天”
第二轮结果显示：
- 在新本体基础上，加回时间约束后，
  - avg_return 上升
  - median 上升
  - trimmed mean 上升

说明：
- 时间约束能过滤掉一部分拖得太久、修复节奏变形的样本
- 它符合 B1 作为**短周期右侧修复**战法的本性

## 七、为什么保留“量能收束方式B”
第二轮结果显示：
- 加回量能收束B后，
  - 胜率略升
  - median 改善
  - trimmed mean 改善
- 与时间约束叠加后，效果进一步增强

说明：
- 量能收束B 并非 V2 里的噪音条件
- 但它更适合作为 **V3 增强结构的一部分**，而不是单独决定胜负的唯一条件
