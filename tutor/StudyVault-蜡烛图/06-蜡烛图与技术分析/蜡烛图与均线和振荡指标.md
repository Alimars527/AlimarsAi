# 蜡烛图与均线和振荡指标 (★★)

#candlestick #western-ta #moving-average #oscillator

## Overview Table (总结)

| 技术工具 | 与蜡烛图结合的方式 | 最佳用途 |
|----------|-------------------|----------|
| **移动平均线** (MA) | 均线作为支撑/阻力，蜡烛图确认反转 | 趋势判断 + 入场时机 |
| **RSI** | 超买/超卖区 + 蜡烛图反转形态 | 反转时机确认 |
| **随机指标** (Stochastic) | 超买/超卖交叉 + 蜡烛图 | 短期反转信号 |
| **MACD** | 背离/交叉 + 蜡烛图 | 中期趋势变化 |

## 蜡烛图 + 移动平均线 ★★★

### 均线作为支撑/阻力

```
上升趋势中价格回到均线 + 出现看涨吞没：

价格 │    *   *
     │   / \ / \
     │  /   *   \→ 看涨吞没出现于均线处
     │ /  ~~~~~~~~ ← 移动平均线
     │/
     └──────────── 时间
```

**核心用法：**

| 应用 | 说明 |
|------|------|
| 均线支撑 + 看涨蜡烛 | 价格回调至均线，出现锤子/吞没 → **买入** |
| 均线阻力 + 看跌蜡烛 | 价格反弹至均线，出现射击之星/乌云盖顶 → **卖出** |
| 均线金叉 + 蜡烛图确认 | 短期均线上穿长期均线 + 看涨蜡烛形态 → **强看涨** |
| 均线死叉 + 蜡烛图确认 | 短期均线下穿长期均线 + 看跌蜡烛形态 → **强看跌** |

### 蜡烛图给均线"提速"

> [!tip] 关键优势
> 均线系统的最大弱点是 **滞后性** —— 信号总是"晚到"。蜡烛图可以在均线发出信号之前提前预警，从而 **弥补均线的滞后性**。

## 蜡烛图 + RSI ★★

### RSI 超买/超卖 + 蜡烛图

| 条件 | 组合信号 | 可靠性 |
|------|----------|--------|
| RSI > 70（超买）+ 看跌蜡烛图 | **卖出** → 双重确认 | 高 |
| RSI < 30（超卖）+ 看涨蜡烛图 | **买入** → 双重确认 | 高 |
| RSI 背离 + 蜡烛图反转 | **极强反转信号** | 极高 |

### RSI 背离 + 蜡烛图

```
价格创新高，但 RSI 没有创新高（顶背离）：

价格:  A     B ← 新高
      / \   /\
     /   \_/  ← 看跌吞没出现于B处

RSI:  a     b ← 未创新高（背离！）
      /\   /\
     /  \_/
```

> [!important] 最强组合之一
> 振荡指标背离 + 蜡烛图反转形态 = 最可靠的反转信号之一。背离说明趋势动能衰竭，蜡烛图确认反转时机。

## 蜡烛图 + 随机指标 (Stochastic) ★

| 应用 | 条件 | 信号 |
|------|------|------|
| 超买区反转 | Stoch > 80 + %K下穿%D + 看跌蜡烛 | 卖出 |
| 超卖区反转 | Stoch < 20 + %K上穿%D + 看涨蜡烛 | 买入 |
| 背离确认 | 价格与Stoch背离 + 蜡烛图形态 | 强信号 |

## 蜡烛图 + MACD ★

| 应用 | 条件 | 信号 |
|------|------|------|
| MACD金叉 + 蜡烛图 | MACD线上穿信号线 + 看涨蜡烛 | 看涨 |
| MACD死叉 + 蜡烛图 | MACD线下穿信号线 + 看跌蜡烛 | 看跌 |
| 零轴上方/下方 | 蜡烛图信号在MACD零轴方向一侧更可靠 | 过滤 |

## 综合使用原则

```
信号可靠性递增：

  单一指标信号 ──→ 两个指标共振 ──→ 三个指标共振
     (低)              (中高)             (高)

例：锤子线 ──→ 锤子线+RSI超卖 ──→ 锤子线+RSI超卖+均线支撑
```

> [!warning] 避免"过度确认"
> 使用2-3个互补工具即可。过多指标会导致"分析瘫痪"——永远等不到所有指标同时确认。关键是选择 **不同类型** 的工具（趋势类+振荡类+蜡烛图）。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "蜡烛图弥补均线的什么弱点？" | **滞后性** —— 蜡烛图可提前预警 |
| "RSI超卖+锤子线" | **双重确认** → 高可靠看涨信号 |
| "最强的反转组合之一？" | **振荡指标背离 + 蜡烛图反转形态** |
| "应该用多少个指标？" | **2-3个互补类型** —— 不要过度确认 |
| "均线金叉+看涨吞没" | **强看涨** —— 趋势方向和反转信号同时确认 |
