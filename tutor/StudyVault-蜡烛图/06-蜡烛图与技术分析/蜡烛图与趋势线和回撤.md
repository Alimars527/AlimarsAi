# 蜡烛图与趋势线和回撤 (★★)

#candlestick #western-ta #trend-analysis

## Overview Table (总结)

| 组合方式 | 核心思路 | 增益效果 |
|----------|----------|----------|
| 蜡烛图 + 趋势线 | 在趋势线处寻找蜡烛图反转形态 | 双重确认，大幅提高可靠性 |
| 蜡烛图 + 回撤水平 | 在 Fibonacci 回撤位观察蜡烛图信号 | 精确定位入场/出场点 |

## 蜡烛图 + 趋势线

### 基本原理

```
上升趋势线 + 锤子线：

价格 │        /
     │       / ← 上升趋势线
     │      /
     │   ┌┐/
     │   ││ ← 价格回到趋势线 + 出现锤子线
     │   └┘
     │    │
     │    * ← 长下影线触及趋势线
     └────────────── 时间
```

**核心逻辑：**
1. 绘制趋势线（连接两个或更多低点/高点）
2. 当价格回到趋势线附近时
3. 观察是否出现蜡烛图 **反转形态**
4. 二者共振 → **高概率信号**

### 应用场景

| 场景 | 蜡烛图信号 | 结合效果 |
|------|-----------|----------|
| 价格回到上升趋势线 | 出现锤子线/看涨吞没 | **强力买入信号** |
| 价格反弹到下降趋势线 | 出现射击之星/看跌吞没 | **强力卖出信号** |
| 价格突破趋势线 | 出现长实体蜡烛 | 突破确认 |
| 趋势线处无蜡烛图信号 | 仅触及趋势线 | 信号较弱，需观察 |

> [!important] 互相验证原则
> 蜡烛图擅长 **发现反转信号**，但不擅长设定价格目标。趋势线/通道线擅长 **定义趋势和目标**，但不擅长预判精确反转点。二者结合 = 各取所长。

## 蜡烛图 + Fibonacci 回撤

### 关键回撤水平

| 回撤比例 | 含义 |
|----------|------|
| **38.2%** | 浅回调 → 强趋势中最常见的回撤水平 |
| **50%** | 中等回调 → 心理关键位 |
| **61.8%** | 深回调 → 黄金分割位，最重要的回撤水平 |

### 组合方法

```
上涨后回调到 61.8% 回撤位 + 出现看涨反转形态：

100% ┤ ← 高点
     │\
     │ \
61.8%┤  \→ ★ 锤子线出现于此 = 强信号
     │
50%  ┤
     │
38.2%┤
     │
0%   ┤ ← 低点
```

| 组合 | 可靠性 |
|------|--------|
| 38.2% 回撤 + 蜡烛图反转 | 中等（浅回调，可能只是暂停） |
| 50% 回撤 + 蜡烛图反转 | 较高 |
| 61.8% 回撤 + 蜡烛图反转 | **高**（黄金分割 + 蜡烛图共振） |
| 多个回撤水平汇聚 + 蜡烛图 | **极高** |

## 支撑/阻力位与蜡烛图

蜡烛图反转形态在以下位置出现时信号最强：

| 关键位类型 | 说明 |
|-----------|------|
| 前期高点/低点 | 历史支撑/阻力 |
| 趋势线 | 动态支撑/阻力 |
| Fibonacci 回撤 | 数学支撑/阻力 |
| 窗口（缺口） | 蜡烛图自身的支撑/阻力 |
| 整数关口 | 心理支撑/阻力 |

> [!tip] 汇聚原则
> 当多种支撑/阻力方法指向 **同一价格区域**，且蜡烛图在该处出现反转形态 → 这是最强的交易信号之一。

| 场景/关键词 | 答案 |
|-------------|------|
| "蜡烛图的弱点是什么？" | 不擅长 **设定价格目标** —— 需要趋势线/通道补充 |
| "趋势线处出现反转蜡烛图形态" | **双重确认** → 高概率信号 |
| "最重要的 Fibonacci 回撤水平？" | **61.8%**（黄金分割） |
| "蜡烛图信号在哪里最可靠？" | 在 **支撑/阻力汇聚区** |
| "蜡烛图+趋势线的核心逻辑？" | 各取所长 —— 蜡烛图找反转，趋势线定方向 |
