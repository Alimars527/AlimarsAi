## 成交量与蜡烛图 ★★★

### 基本原则

> [!important] 成交量是蜡烛图信号的"证人"
> 蜡烛图形态如同"宣判"，成交量如同"证人证词"——有成交量配合的形态比无配合的更可信。

| 成交量规律 | 含义 |
|-----------|------|
| 反转形态 + **放量** | 信号增强 → 大量资金参与方向转换 |
| 反转形态 + **缩量** | 信号减弱 → 转向力度不足 |
| 突破 + 放量 | 真突破概率高 |
| 突破 + 缩量 | 假突破概率高 |

### 具体应用

| 蜡烛图形态 | 理想成交量配合 |
|-----------|---------------|
| **锤子线** | 锤子线当日放量 → 强看涨 |
| **看涨吞没** | 第2天（阳线）放量 > 第1天 → 买盘强劲 |
| **启明星** | 第1天放量 → 第2天缩量 → 第3天放量 |
| **乌云盖顶** | 第2天（阴线）放量 → 卖压沉重 |
| **三白兵** | 每天逐步放量 → 买盘持续涌入 |
| **窗口** | 跳空日放量 → 趋势动能强劲 |

### 成交量分析的特殊规则

```
异常放量 + 蜡烛图信号：

           ┌──┐
成交量 │   │▓▓│ ← 巨量长阴线（下跌投降式抛售）
       │   │▓▓│
  ═════│===│▓▓│=== ← 平均成交量线
       │   │▓▓│
       └───┴──┴──

→ 可能是 **恐慌性抛售的高潮** → 看涨反转信号（卖方力竭）
```

> [!warning] 高潮放量的双面性
> 极端放量可以是趋势的 **加速** 也可以是 **终结**。在下降趋势末端的恐慌性放量常标志着 **卖方高潮**（climax）→ 反转在即。但在上升趋势中的放量通常是 **正常的趋势确认**。

## OBV (能量潮) 与蜡烛图 ★

| 组合 | 含义 |
|------|------|
| OBV 上升 + 看涨蜡烛图 | 趋势+资金流向一致 → **强看涨** |
| OBV 下降 + 看跌蜡烛图 | 趋势+资金流向一致 → **强看跌** |
| OBV 背离 + 蜡烛图反转 | 资金已先行转向 → **极强反转信号** |

## 综合应用：构建交易系统 ★★★

Steve Nison 的核心哲学：蜡烛图不是独立系统，而是融合工具。

### 交易决策框架

```
第1步：确定大趋势方向（均线、趋势线）
  ↓
第2步：识别关键支撑/阻力位（水平线、Fibonacci、窗口）
  ↓
第3步：在关键位寻找蜡烛图反转/持续形态
  ↓
第4步：用振荡指标确认（RSI/Stochastic 是否配合）
  ↓
第5步：检查成交量确认
  ↓
第6步：执行交易（设止损于蜡烛图形态另一侧）
```

### 蜡烛图止损设置法

| 形态 | 止损位置 |
|------|----------|
| **锤子线** 买入 | 止损设在锤子线下影线 **下方** |
| **看涨吞没** 买入 | 止损设在吞没形态最低点 **下方** |
| **启明星** 买入 | 止损设在星体（第2天）最低点 **下方** |
| **射击之星** 卖出 | 止损设在射击之星上影线 **上方** |

> [!tip] 蜡烛图的天然止损优势
> 蜡烛图形态自带 **明确的止损参考点**——形态的极端价位。这是蜡烛图在风险管理方面的独特优势。

### 综合应用注意事项

| 原则 | 说明 |
|------|------|
| **不要过度分析** | 2-3个工具互相验证足矣 |
| **蜡烛图优先** | 蜡烛图信号应最先被注意到 |
| **背景决定一切** | 同一形态在不同市场背景下含义不同 |
| **风险管理第一** | 没有100%可靠的形态，永远要设止损 |
| **实践出真知** | 大量看图练习比记忆理论更重要 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "蜡烛图形态+放量的意义？" | **信号增强** —— 成交量是信号的"证人" |
| "下降趋势末端恐慌性放量" | 可能是 **卖方高潮** → 看涨反转 |
| "锤子线买入后止损设哪里？" | 锤子线 **下影线下方** |
| "蜡烛图在风险管理上的优势？" | 形态自带 **天然止损参考点** |
| "完整交易框架的步骤？" | 趋势→支撑阻力→蜡烛图形态→指标确认→成交量→执行 |
