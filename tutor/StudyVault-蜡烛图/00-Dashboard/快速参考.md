# 蜡烛图形态速查表

#dashboard #candlestick

## 一、单蜡烛线形态 → [[锤子线与上吊线]] [[十字线]] [[其他单线形态]]

| 形态 | 外观 | 位置 | 信号 | 确认 |
|------|------|------|------|------|
| **锤子线** | 小实体上+长下影(≥2x) | 底部 | 看涨 | 有则更好 |
| **上吊线** | 小实体上+长下影(≥2x) | 顶部 | 看跌 | **必须** |
| **射击之星** | 小实体下+长上影(≥2x) | 顶部 | 看跌 | 是 |
| **倒锤子线** | 小实体下+长上影(≥2x) | 底部 | 看涨 | **必须** |
| **墓碑十字** | 开=收=低+长上影 | 顶部 | 强看跌 | 是 |
| **蜻蜓十字** | 开=收=高+长下影 | 底部 | 强看涨 | 是 |
| **长脚十字** | 开=收+上下长影 | 顶/底 | 强犹豫 | 必须 |
| **光头光脚阳** | 无影线长阳 | 任意 | 极强看涨 | — |
| **光头光脚阴** | 无影线长阴 | 任意 | 极强看跌 | — |
| **纺锤线** | 短实体+上下影 | 任意 | 犹豫 | — |

## 二、双蜡烛线形态 → [[吞没形态]] [[乌云盖顶与刺透形态]] [[孕线与其他双线形态]]

| 形态 | 结构 | 位置 | 信号 | 深入度 |
|------|------|------|------|--------|
| **看涨吞没** | 阴+大阳(包裹) | 底部 | 强看涨 | >100% |
| **看跌吞没** | 阳+大阴(包裹) | 顶部 | 强看跌 | >100% |
| **乌云盖顶** | 阳+高开阴(深入50%↓) | 顶部 | 看跌 | >50% |
| **刺透形态** | 阴+低开阳(深入50%↑) | 底部 | 看涨 | >50% |
| **看跌孕线** | 大阳含小阴 | 顶部 | 中看跌 | 被包含 |
| **看涨孕线** | 大阴含小阳 | 底部 | 中看涨 | 被包含 |
| **十字孕线** | 大蜡烛含十字 | 顶/底 | 强 | 被包含 |
| **平头顶/底** | 同高/同低 | 顶/底 | 中等 | — |
| **捉腰带线** | 跳空+光脚/光头 | 顶/底 | 中等 | — |
| **反击线** | 颜色反+同收盘 | 顶/底 | 弱 | 0% |

## 三、多蜡烛线形态 → [[星线形态]] [[三兵三鸦与其他多线形态]]

| 形态 | 结构 | 位置 | 信号 |
|------|------|------|------|
| **启明星** | 阴+跳空小实体+阳 | 底部 | 强看涨 |
| **黄昏星** | 阳+跳空小实体+阴 | 顶部 | 强看跌 |
| **十字启明星** | 阴+跳空十字+阳 | 底部 | 极强看涨 |
| **十字黄昏星** | 阳+跳空十字+阴 | 顶部 | 极强看跌 |
| **看涨弃婴** | 阴→⬇跳⬇→十字→⬆跳⬆→阳 | 底部 | 极强看涨 |
| **看跌弃婴** | 阳→⬆跳⬆→十字→⬇跳⬇→阴 | 顶部 | 极强看跌 |
| **三白兵** | 3阳依次上升 | 底部 | 强看涨 |
| **三只乌鸦** | 3阴依次下降 | 顶部 | 强看跌 |
| **三山/三尊** | 3次试探同高 | 顶部 | 看跌 |
| **三川/倒三尊** | 3次试探同低 | 底部 | 看涨 |

## 四、持续形态 → [[窗口与缺口]] [[三法与其他持续形态]]

| 形态 | 结构 | 趋势 | 信号 |
|------|------|------|------|
| **向上窗口** | 后低>前高(跳空) | 上升 | 看涨持续(=支撑) |
| **向下窗口** | 后高<前低(跳空) | 下降 | 看跌持续(=阻力) |
| **上升三法** | 长阳+3小阴+长阳 | 上升 | 看涨持续 |
| **下降三法** | 长阴+3小阳+长阴 | 下降 | 看跌持续 |
| **递进(Tasuki)** | 跳空+部分回补 | 同趋势 | 持续 |

## 五、关键公式与条件 → [[反转形态基本概念]] [[蜡烛图与成交量及综合应用]]

| 规则 | 条件表达式 |
|------|-----------|
| 阳线判定 | Close > Open |
| 锤子线下影线 | Lower Shadow ≥ 2 × Real Body |
| 乌云盖顶深入 | Close₂ < (Open₁ + Close₁) / 2 |
| 吞没条件 | Open₂ < Close₁ AND Close₂ > Open₁ (看涨) |
| 窗口(向上) | Low₂ > High₁ |
| 三法有效性 | All small candles within [Low₁, High₁] |
| 三窗口耗竭 | 第3个窗口出现 → 警惕反转 |
| 确认信号 | 次日沿反转方向的蜡烛线 |
