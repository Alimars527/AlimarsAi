# 吞没形态 (★★★)

#candlestick #dual-line #reversal-pattern

## Overview Table (总结)

| 形态 | 结构 | 位置 | 信号 |
|------|------|------|------|
| **看涨吞没** | 阴线 + 大阳线（完全包住前阴） | 下降趋势底部 | 强看涨 |
| **看跌吞没** | 阳线 + 大阴线（完全包住前阳） | 上升趋势顶部 | 强看跌 |

## 形态定义与结构

```
看涨吞没 (Bullish Engulfing)      看跌吞没 (Bearish Engulfing)

  ┌──┐                                 ┌────┐
  │▓▓│ ← 第1天：阴线               │    │ ← 第1天：阳线
  └──┘                                 └────┘
┌────┐                              ┌──────┐
│    │                              │▓▓▓▓▓▓│
│    │ ← 第2天：大阳线              │▓▓▓▓▓▓│ ← 第2天：大阴线
│    │   实体完全包裹第1天          │▓▓▓▓▓▓│   实体完全包裹第1天
└────┘                              └──────┘
```

**识别标准（严格三条件）：**

1. **先有明确趋势**（下降→看涨吞没；上升→看跌吞没）
2. 第二根蜡烛的实体 **完全吞没（包裹）** 第一根蜡烛的实体
3. 第一根实体较小，第二根实体较大（颜色相反）

> [!important] "吞没"的标准
> 是 **实体** 吞没实体，不要求影线也被包裹。第二根的实体必须同时超过第一根实体的上端和下端。

## 看涨吞没 详解

| 要素 | 说明 |
|------|------|
| 市场心理 | 下降趋势中空方打出阴线，但次日多方强力开低走高，完全逆转前一天失地 |
| 信号强度 | 双线反转形态中 **最强之一** |
| 意义 | 多方一天之内完全压制空方 |

**增强因素：**

| 条件 | 效果 |
|------|------|
| 第一根实体很小 + 第二根实体很大 | 对比越大，信号越强 |
| 吞没发生在长期下降趋势之后 | 趋势越长，反转越有力 |
| 第二天伴随 **放量** | 确认买盘力度 |
| 第二根蜡烛同时吞没 **多根** 之前的实体 | 极强信号 |
| 出现在 **支撑位** | 可靠性大增 |

## 看跌吞没 详解

| 要素 | 说明 |
|------|------|
| 市场心理 | 上升趋势中多方打出阳线，但次日空方强力开高走低，完全吞噬前一天涨幅 |
| 信号强度 | 双线反转形态中 **最强之一** |
| 确认 | 第三天继续收阴或低开则确认 |

## 常见失误与边界情况

> [!warning] 易错点
> 1. **仅影线超过** 不算吞没 —— 必须是 **实体** 完全包裹
> 2. **横盘中出现** 吞没形态意义减弱 —— 需要先有趋势
> 3. 第一根是 **十字线** 被吞没 → 信号更强（十字线表示犹豫，吞没=打破犹豫）
> 4. 与 **外包线** 的区别：外包线要求影线也被包裹，吞没仅要求实体

## 吞没形态 vs 类似形态

| 对比 | 吞没形态 | 乌云盖顶/刺透 |
|------|----------|----------------|
| 覆盖程度 | 完全吞没（100%+） | 部分侵入（>50%） |
| 信号强度 | 更强 | 较强 |
| 第二根开盘 | 超过第一根实体范围 | 超过第一根最高/最低 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "下降趋势底部，第二天大阳线包住前一天小阴线" | **看涨吞没** —— 强看涨反转 |
| "什么增强吞没形态的信号？" | 实体对比大、趋势长、放量、在支撑/阻力位 |
| "吞没需要影线也被包裹吗？" | **不需要** —— 仅要求实体 |
| "横盘市场中出现吞没形态" | **信号减弱** —— 缺少前置趋势 |
| "一根蜡烛吞没前面3根的实体" | **极强信号** —— 多根吞没比单根更有力 |
