# 孕线与其他双线形态 (★★)

#candlestick #dual-line #reversal-pattern

## Overview Table (总结)

| 形态 | 结构 | 位置 | 信号强度 |
|------|------|------|----------|
| **孕线** (Harami) | 大实体 + 小实体（被包含） | 顶/底 | 中等 |
| **十字孕线** (Harami Cross) | 大实体 + 十字线 | 顶/底 | 强 |
| **平头** (Tweezers) | 两根蜡烛最高/最低价相同 | 顶/底 | 中等 |
| **捉腰带线** (Belt Hold) | 跳空 + 光脚/光头大蜡烛 | 顶/底 | 中等 |
| **反击线** (Counterattack) | 两根颜色相反，收盘价相同 | 顶/底 | 中等 |

## 孕线形态 (Harami) ★★★

"Harami" 是日语"怀孕"之意 —— 第一根是"母亲"，第二根是"婴儿"。

```
看跌孕线               看涨孕线
(上升趋势顶部)         (下降趋势底部)

┌──────┐               ┌──────┐
│      │               │▓▓▓▓▓▓│
│ ┌──┐ │               │ ┌──┐ │
│ │▓▓│ │ ← 小阴线      │ │  │ │ ← 小阳线
│ └──┘ │   被包含       │ └──┘ │   被包含
│      │               │▓▓▓▓▓▓│
└──────┘               └──────┘
 大阳线                  大阴线
```

**识别标准：**
1. 第1根为长实体蜡烛线
2. 第2根为短实体蜡烛线，**完全包含在** 第1根实体之内
3. 颜色通常相反（但不强制）

| 要素 | 说明 |
|------|------|
| 本质 | **吞没形态的反转** —— 方向刚好相反 |
| 信号强度 | 弱于吞没形态 |
| 市场心理 | 趋势推动力量突然 **大幅减弱**，犹如"怀孕"后行动不便 |
| 确认 | 需要第3根蜡烛确认方向 |

> [!tip] 孕线 vs 吞没 —— 互为"反义词"
> - **吞没**：第2根包裹第1根 → 新力量 **碾压** 旧力量
> - **孕线**：第2根被包含在第1根内 → 旧力量 **衰竭**，新力量尚未明确

### 十字孕线 (Harami Cross) ★★★

当孕线的第2根蜡烛是 **十字线** 时，形成十字孕线，信号 **显著增强**。

| 对比 | 普通孕线 | 十字孕线 |
|------|----------|----------|
| 第2根 | 小实体 | 十字线（开盘=收盘） |
| 信号强度 | 中等 | **强** |
| 原因 | 力量减弱 | 力量 **完全丧失**（十字线=犹豫到极致） |

## 平头形态 (Tweezers Top/Bottom) ★★

```
平头顶部 (Tweezers Top)     平头底部 (Tweezers Bottom)

  ┌──┐  ┌──┐                     ┌──┐
  │  │  │▓▓│                     │▓▓│  
  │  │  │▓▓│ ← 两根蜡烛          │▓▓│
  └──┘  └──┘   最高价相同        └──┘  ┌──┐
  ════════ ← 相同最高价               │  │
                                      │  │
                                      └──┘
                                 ════════ ← 相同最低价
```

| 要素 | 说明 |
|------|------|
| 定义 | 相邻两根（或更多）蜡烛线的最高价或最低价 **几乎相同** |
| 平头顶部 | 最高价相同 → 上方有共同阻力 → **看跌** |
| 平头底部 | 最低价相同 → 下方有共同支撑 → **看涨** |
| 增强因素 | 与其他反转形态同时出现（如平头 + 孕线） |

## 捉腰带线 (Belt Hold) ★

| 类型 | 结构 | 信号 |
|------|------|------|
| **看涨捉腰带** | 下跌中出现 **开盘光脚阳线**（开盘=最低，无下影） | 看涨 |
| **看跌捉腰带** | 上涨中出现 **开盘光头阴线**（开盘=最高，无上影） | 看跌 |

> 实体越长，信号越可靠。相当于一根"几乎光头光脚"的长蜡烛。

## 反击线 (Counterattack Lines) ★

| 要素 | 说明 |
|------|------|
| 结构 | 两根颜色相反的蜡烛线，**收盘价相同或极接近** |
| 看涨反击 | 下跌中：阴线 + 低开后收阳至前阴收盘价 |
| 看跌反击 | 上涨中：阳线 + 高开后收阴至前阳收盘价 |
| vs 乌云盖顶 | 反击线只收到前实体收盘位；乌云盖顶深入实体内部 |
| 信号强度 | 弱于乌云盖顶/刺透，是最弱的双线反转形态之一 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "大阳线后出现小阴线被完全包含" | **看跌孕线** |
| "孕线和吞没形态的关系？" | **互为反义** —— 吞没=第2包第1；孕线=第1包第2 |
| "十字孕线为什么比普通孕线强？" | 十字线 = 犹豫到极致，力量 **完全丧失** |
| "两根蜡烛最高价相同" | **平头顶部** —— 上方共同阻力 |
| "反击线 vs 乌云盖顶？" | 反击线只到收盘位，**乌云盖顶深入实体内部**，更强 |
