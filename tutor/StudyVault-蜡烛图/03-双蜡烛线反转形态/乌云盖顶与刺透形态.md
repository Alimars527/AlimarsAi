# 乌云盖顶与刺透形态 (★★★)

#candlestick #dual-line #reversal-pattern

## Overview Table (总结)

| 形态 | 第1根 | 第2根 | 位置 | 信号 |
|------|-------|-------|------|------|
| **乌云盖顶** (Dark Cloud Cover) | 阳线 | 高开阴线，收于前阳实体50%↓ | 上升顶部 | 看跌 |
| **刺透形态** (Piercing Pattern) | 阴线 | 低开阳线，收于前阴实体50%↑ | 下降底部 | 看涨 |

## 乌云盖顶 (Dark Cloud Cover) ★★★

```
      ┌────┐
      │▓▓▓▓│ ← 第2天：高开后收阴
      │▓▓▓▓│   收盘深入前阳实体50%以下
  ┌───┤▓▓▓▓│
  │   └────┘
  │   │ ← 第1天：阳线
  └───┘
```

**识别标准：**
1. 上升趋势中
2. 第1天是一根 **较长阳线**
3. 第2天 **高开**（开盘价高于前一天最高价）
4. 第2天收阴，且 **收盘价深入** 前阳实体的 **50% 以下**

| 要素 | 说明 |
|------|------|
| 市场心理 | 多方延续上涨（高开），但空方强力反击将价格打至前阳实体过半以下 |
| 50% 规则 | 深入越多，信号越强。**不到 50% 则不算标准乌云盖顶** |
| 确认 | 第3天收阴或低开则确认 |

**增强因素：**
- 第2天开盘 **远高于** 前一天最高价（跳空越大，失败越惨）
- 第2天侵入前阳的深度 **越大** 越好
- 伴随 **放量**
- 出现在 **阻力位**

> [!warning] 50% 的临界标准
> 如果第2天阴线没有深入前阳实体的 50%，则只能算 **疑似乌云盖顶**，需要更多确认信号。这个 50% 标准是判定的关键门槛。

## 刺透形态 (Piercing Pattern) ★★★

```
  ┌───┐
  │▓▓▓│ ← 第1天：阴线
  │▓▓▓├───┐
  └───┤   │
      │   │ ← 第2天：低开后收阳
      │   │   收盘深入前阴实体50%以上
      └───┘
```

**识别标准：**
1. 下降趋势中
2. 第1天是一根 **较长阴线**
3. 第2天 **低开**（开盘价低于前一天最低价）
4. 第2天收阳，且 **收盘价深入** 前阴实体的 **50% 以上**

| 要素 | 说明 |
|------|------|
| 市场心理 | 空方延续下跌（低开），但多方强力反攻收复前阴过半失地 |
| 与看涨吞没的区别 | 刺透形态只深入50%+，吞没则完全包裹 |
| 信号强度 | 弱于看涨吞没，但仍是重要的看涨反转信号 |

## 乌云盖顶 vs 刺透形态

| 对比项 | 乌云盖顶 | 刺透形态 |
|--------|----------|----------|
| 方向 | 看跌 | 看涨 |
| 前置趋势 | 上升 | 下降 |
| 第2天开盘 | 高于前最高价 | 低于前最低价 |
| 深入程度 | 收于前实体50%以下 | 收于前实体50%以上 |
| 互为关系 | **互为镜像** | **互为镜像** |

## 与吞没形态的关系

```
深入程度：

0%   ──→ 无信号
30%  ──→ 不合格
50%  ──→ 乌云盖顶 / 刺透形态 ← 最低门槛
80%  ──→ 强信号
100% ──→ 吞没形态（完全超过）
```

> [!important] 递进关系
> **刺透 → 看涨吞没**：刺透是"不完全吞没"，如果第2天收盘完全超过第1天实体上端，则升级为看涨吞没（信号更强）。乌云盖顶与看跌吞没同理。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "上升趋势顶，阳线后高开收阴深入50%以下" | **乌云盖顶** —— 看跌反转 |
| "第2天阴线只深入前阳的30%" | **不合格** —— 不是标准乌云盖顶 |
| "刺透形态和看涨吞没的区别？" | **深入程度** —— 刺透只超50%，吞没完全包裹 |
| "乌云盖顶和刺透形态的关系？" | **互为镜像** —— 方向相反，结构对称 |
| "高开越多对乌云盖顶的意义？" | **跳空越大，反转信号越强**（开多高就跌多惨） |
