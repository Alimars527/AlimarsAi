# 窗口与缺口 (★★★)

#candlestick #continuation-pattern

## Overview Table (总结)

| 类型 | 方向 | 含义 | 支撑/阻力 |
|------|------|------|-----------|
| **向上窗口** (Rising Window) | 上涨中跳空 | 看涨持续 | 窗口 = 支撑区 |
| **向下窗口** (Falling Window) | 下跌中跳空 | 看跌持续 | 窗口 = 阻力区 |

## 窗口的定义

"窗口" 是日本蜡烛图中对"跳空缺口"的称呼。

```
向上窗口                     向下窗口

      ┌──┐                  ┌──┐
      │  │ ← 后蜡烛          │▓▓│ ← 前蜡烛
      │  │                   │▓▓│
      └──┘                   └──┘
      ═══ ← 窗口（缺口）     ═══ ← 窗口（缺口）
      ┌──┐   前蜡烛最高价     ┌──┐   后蜡烛最高价
      │  │   < 后蜡烛最低价   │▓▓│   < 前蜡烛最低价
      └──┘                   │▓▓│
                              └──┘
```

**精确定义：**
- **向上窗口**：后一根蜡烛的 **最低价** > 前一根蜡烛的 **最高价**
- **向下窗口**：后一根蜡烛的 **最高价** < 前一根蜡烛的 **最低价**

## 窗口的核心法则

### 法则一：窗口 = 支撑/阻力

| 窗口类型 | 作用 |
|----------|------|
| 向上窗口 | 该区域成为 **支撑区** → 回调至此应获得支撑 |
| 向下窗口 | 该区域成为 **阻力区** → 反弹至此应遇到阻力 |

> [!important] 日本古训
> "回调至窗口时买入"（向上窗口）或"反弹至窗口时卖出"（向下窗口）。窗口是最天然的支撑/阻力位。

### 法则二：窗口终将关闭

- 日本分析师认为 **价格最终会回来填补窗口**
- 但关键在于"何时"以及"填补后是否继续原趋势"

### 法则三：连续三个窗口 = 耗竭

| 序列 | 含义 |
|------|------|
| 第1个窗口 | 突破型 —— 趋势启动 |
| 第2个窗口 | 持续型 —— 趋势延续 |
| 第3个窗口 | **耗竭型** —— 趋势可能即将反转 |

```
上升趋势中三个窗口：

              ┌──┐
              │  │ 第3个窗口后 → ⚠️ 警惕反转
         ═══ │  │
         ┌──┐└──┘
         │  │
    ═══  │  │
    ┌──┐ └──┘
    │  │
═══ │  │
    └──┘
```

> [!warning] 三窗口法则
> 上升趋势中出现三个向上窗口后，日本分析师认为趋势已近尾声。这与西方"跳空理论"中的耗竭缺口概念高度吻合。

## 窗口与其他蜡烛图形态的结合

| 组合 | 含义 |
|------|------|
| 向上窗口 + 反转形态 | 窗口位置成为关键支撑测试区 |
| 向下窗口 + 锤子线 | 如果锤子线出现在窗口处 → 强支撑 |
| 三个窗口后 + 十字线 | **极强反转信号** |

## 窗口 vs 西方缺口理论

| 对比 | 日本（窗口） | 西方（缺口） |
|------|-------------|-------------|
| 名称 | 窗口 (Window / Ku) | 缺口 (Gap) |
| 分类 | 按数量（1st, 2nd, 3rd） | 按功能（突破/持续/耗竭） |
| 支撑/阻力 | ✓ 核心概念 | ✓ 也认可 |
| 填补理论 | ✓ 窗口终将关闭 | ✓ 缺口倾向回补 |
| 结论 | **殊途同归** | **殊途同归** |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "向上窗口形成后价格回落到窗口区域" | 窗口应提供 **支撑**，可考虑买入 |
| "上涨中出现第三个窗口" | ⚠️ **耗竭信号** —— 趋势可能即将反转 |
| "窗口等于西方的什么？" | **缺口 (Gap)** |
| "窗口的最重要作用？" | 形成 **支撑/阻力区域** |
| "向上窗口的精确定义？" | 后一根蜡烛最低价 **>** 前一根蜡烛最高价 |
