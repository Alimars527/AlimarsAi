# 三法与其他持续形态 (★★)

#candlestick #continuation-pattern

## Overview Table (总结)

| 形态 | 结构 | 趋势 | 信号 |
|------|------|------|------|
| **上升三法** | 长阳 + 3小阴 + 长阳 | 上升 | 看涨持续 |
| **下降三法** | 长阴 + 3小阳 + 长阴 | 下降 | 看跌持续 |
| **向上跳空并列阳线** | 跳空 + 两根相似阳线 | 上升 | 看涨持续 |
| **递进蜡烛线** (Tasuki) | 跳空 + 反向蜡烛 | 同趋势 | 持续 |
| **分手线** | 同开盘价，方向相反 | 同趋势 | 持续 |

## 上升三法 (Rising Three Methods) ★★★

```
         第5天
    ┌──┐  ↑
    │  │ ┌───┐
┌─┐ │  │ │   │
│▓│ │  │ │   │
└─┘ │  │ │   │
 ┌─┐│  │ │   │
 │▓│└──┘ └───┘
 └─┘
  ↓  3根小阴线  ↑
第1天          第5天
长阳           长阳
```

**识别标准（五根蜡烛）：**
1. 第1根 = **长阳线**（确立上升趋势）
2. 中间 = **三根（或更多）小阴线**，逐步回落
   - 小阴线必须包含在第1根阳线的高低范围内
3. 第5根 = **长阳线**，收盘创新高（超过第1根的收盘）

| 要素 | 说明 |
|------|------|
| 市场心理 | 上涨暂歇 → 小幅回调（空方无力继续打压）→ 多方恢复上攻 |
| 本质 | "中继旗形"——暂时的回调整理后趋势继续 |
| 关键 | 小阴线 **不得跌破** 第1根阳线的最低价 |

> [!tip] 类比
> 上升三法 ≈ 西方技术分析中的 **看涨旗形**（Bull Flag）。短暂回调后原趋势恢复。

## 下降三法 (Falling Three Methods) ★★★

上升三法的 **看跌镜像**。

| 对比 | 上升三法 | 下降三法 |
|------|----------|----------|
| 第1天 | 长阳 | 长阴 |
| 中间 | 3根小阴 | 3根小阳 |
| 最后1天 | 长阳（创新高） | 长阴（创新低） |
| 含义 | 看涨持续 | 看跌持续 |
| 限制 | 小阴不破第1根低点 | 小阳不破第1根高点 |

## 递进蜡烛线 (Tasuki Gap) ★

```
向上递进:           向下递进:

    ┌──┐               ┌──┐
    │  │ ┌──┐          │▓▓│
    └──┘ │▓▓│ ← 部分   └──┘ ┌──┐
 ═══     │▓▓│   填补      ═══│  │ ← 部分填补
 ┌──┐    └──┘          ┌──┐ │  │   缺口
 │  │               │▓▓│ └──┘
 └──┘               └──┘
```

| 类型 | 结构 | 含义 |
|------|------|------|
| 向上递进 | 阳线→跳空阳线→**阴线部分填补跳空** | 若阴线未完全关闭窗口 → **看涨持续** |
| 向下递进 | 阴线→跳空阴线→**阳线部分填补跳空** | 若阳线未完全关闭窗口 → **看跌持续** |

> [!warning] 关键判断
> 如果反向蜡烛 **完全关闭了窗口** → 持续形态失败，可能转为反转信号。

## 并列阳线/阴线 (Side-by-Side Lines) ★

| 类型 | 结构 | 含义 |
|------|------|------|
| 向上跳空并列阳线 | 跳空后出现两根大小相近的阳线 | 看涨持续 |
| 向下跳空并列阴线 | 跳空后出现两根大小相近的阴线 | 看跌持续 |

## 分手线 (Separating Lines) ★

| 类型 | 结构 | 含义 |
|------|------|------|
| 看涨分手线 | 上升中：阴线 → 同开盘价的阳线（光脚阳） | 看涨持续 |
| 看跌分手线 | 下降中：阳线 → 同开盘价的阴线（光头阴） | 看跌持续 |

特征：两根蜡烛开盘价相同，但方向相反。趋势方向的那根（第2根）更为强势。

## 持续形态 vs 反转形态 总结

| 对比 | 持续形态 | 反转形态 |
|------|----------|----------|
| 含义 | 趋势 **暂歇后继续** | 趋势 **改变方向** |
| 出现位置 | 趋势中途 | 趋势末端 |
| 典型代表 | 三法、窗口、递进 | 吞没、星线、锤子 |
| 实战建议 | 顺势加仓的机会 | 平仓或反向操作的信号 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "长阳+3小阴(在阳线范围内)+长阳创新高" | **上升三法** —— 看涨持续 |
| "上升三法中间小阴线跌破第1天低点" | **形态失效** —— 不再是上升三法 |
| "上升三法≈西方的什么形态？" | **看涨旗形 (Bull Flag)** |
| "递进蜡烛线的关键判断？" | 反向蜡烛是否 **完全关闭窗口** |
| "持续形态的实战意义？" | **顺势加仓** 的机会 |
