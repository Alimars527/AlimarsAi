# 星线形态 (★★★)

#candlestick #multi-line #star-pattern #reversal-pattern

## Overview Table (总结)

| 形态 | 结构 | 位置 | 信号 |
|------|------|------|------|
| **启明星** (Morning Star) | 阴 + 小实体(跳空) + 阳 | 下降底部 | 强看涨 |
| **黄昏星** (Evening Star) | 阳 + 小实体(跳空) + 阴 | 上升顶部 | 强看跌 |
| **十字启明星** | 阴 + 十字线(跳空) + 阳 | 下降底部 | 极强看涨 |
| **十字黄昏星** | 阳 + 十字线(跳空) + 阴 | 上升顶部 | 极强看跌 |
| **弃婴** (Abandoned Baby) | 含跳空十字的星线 | 顶/底 | 极强 |

## 启明星 (Morning Star) ★★★

```
第1天      第2天       第3天
         (启明星体)

┌──┐
│▓▓│
│▓▓│                  ┌───┐
│▓▓│    ↗ 跳空 ↘     │   │
│▓▓│     ┌─┐         │   │
└──┘     │ │          │   │
         └─┘          │   │
  阴线   小实体        └───┘
(下降中) (犹豫/跳空)   阳线(收复)
```

**三根蜡烛的含义：**

| 第N天 | 角色 | 含义 |
|-------|------|------|
| 第1天 | 长阴线 | 空方仍在控盘 |
| 第2天 | 小实体（跳空低开） | 空方力量 **衰竭**，多空出现均衡 |
| 第3天 | 长阳线 | 多方 **强力反攻**，收复第1天大部分失地 |

**识别标准：**
1. 下降趋势中
2. 第1天 = 长阴线
3. 第2天 = 小实体，与第1天实体之间存在 **跳空**（理想状态）
4. 第3天 = 长阳线，深入第1天阳线实体 **50% 以上**

> [!tip] 记忆法
> **启明星** = 黎明前的星星 → 预示"黑夜"（下跌）即将结束，"白天"（上涨）即将来临。

## 黄昏星 (Evening Star) ★★★

```
第1天       第2天       第3天
          (黄昏星体)

           ┌─┐
          │ │ ← 小实体(跳空高开)
┌───┐     └─┘
│   │                  ┌──┐
│   │    ↘ 跳空 ↗     │▓▓│
│   │                  │▓▓│
│   │                  │▓▓│
└───┘                  └──┘
 阳线     小实体       阴线(大跌)
```

| 要素 | 说明 |
|------|------|
| 含义 | 启明星的 **完美镜像** |
| 市场心理 | 多方最后冲刺（跳空高开），但无以为继，空方发起反攻 |
| 第3天关键 | 阴线收盘须深入第1天阳线实体 50%+ |

> [!tip] 记忆法
> **黄昏星** = 傍晚的星星 → 预示"白天"（上涨）即将结束，"黑夜"（下跌）即将来临。

## 十字星变体

### 十字启明星 / 十字黄昏星

当星体（第2天）是 **十字线** 时，信号 **大幅增强**。

| 对比 | 普通星线 | 十字星线 |
|------|----------|----------|
| 第2天 | 小实体 | 十字线 |
| 信号强度 | 强 | **极强** |
| 原因 | 犹豫 | **完全犹豫** → 力量彻底均衡 |

### 弃婴形态 (Abandoned Baby) ★★★

**最强的三线反转形态之一。**

| 要素 | 说明 |
|------|------|
| 定义 | 十字星线的两侧都有 **跳空**（与前后蜡烛影线都不重叠） |
| 看涨弃婴 | 阴 → ⬇跳空⬇ → 十字线 → ⬆跳空⬆ → 阳 |
| 看跌弃婴 | 阳 → ⬆跳空⬆ → 十字线 → ⬇跳空⬇ → 阴 |
| 特征 | 十字线如被"遗弃"在跳空之间 |
| 出现频率 | **非常罕见** |
| 信号强度 | **极强** |

> [!important] 弃婴 vs 普通十字星线
> 普通十字星线只要求第2天跳空；弃婴要求 **两侧都跳空**，十字线孤悬在缺口中间。这使得弃婴形态比十字星更为罕见但信号更强。

## 星线形态增强因素总结

| 增强条件 | 说明 |
|----------|------|
| 第2天与两侧都有跳空 | 信号最强（弃婴） |
| 第2天是十字线 | 比小实体更强 |
| 第3天深入第1天实体越深 | 反转力度越大 |
| 伴随成交量变化 | 第1天放量→第2天缩量→第3天放量 |
| 出现在关键支撑/阻力位 | 可靠性大增 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "下降趋势底，阴+跳空小实体+阳" | **启明星** —— 看涨反转 |
| "启明星和黄昏星的关系？" | **完美镜像** —— 方向相反，结构对称 |
| "星体是十字线时信号如何？" | **大幅增强** —— 十字=完全犹豫 |
| "弃婴形态最特殊的地方？" | 十字线 **两侧都有跳空** |
| "星线形态属于几根蜡烛线？" | **三根** —— 第1天趋势+第2天星体+第3天反转 |
