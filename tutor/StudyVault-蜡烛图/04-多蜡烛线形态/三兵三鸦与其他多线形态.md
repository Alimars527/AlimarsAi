# 三兵三鸦与其他多线形态 (★★)

#candlestick #multi-line #reversal-pattern

## Overview Table (总结)

| 形态 | 蜡烛数 | 信号 | 可靠性 |
|------|--------|------|--------|
| **三白兵** (Three White Soldiers) | 3 阳 | 强看涨 | 高 |
| **三只乌鸦** (Three Black Crows) | 3 阴 | 强看跌 | 高 |
| **向上跳空二只乌鸦** | 2阴+跳空 | 看跌 | 中 |
| **三山** (Three Mountains) | 多根 | 看跌（顶） | 高 |
| **三川** (Three Rivers) | 多根 | 看涨（底） | 高 |
| **塔形顶/底** | 多根 | 反转 | 中 |

## 三白兵 (Three White Soldiers) ★★★

```
              ┌──┐
         ┌──┐ │  │
    ┌──┐ │  │ │  │
    │  │ │  │ │  │
    │  │ │  │ └──┘
    │  │ └──┘
    └──┘
   第1天  第2天  第3天
```

**识别标准：**
1. 三根 **依次上升** 的阳线
2. 每根的 **收盘价接近当天最高价**（短上影线或无上影线）
3. 每根的 **开盘价在前一根实体范围之内**

| 要素 | 说明 |
|------|------|
| 含义 | 多方连续三天强力推进，**买盘坚定** |
| 最佳位置 | 下降趋势底部或长期横盘之后 |
| 关键细节 | 每根蜡烛实体大小应 **大致相当**，不应逐渐缩小 |

> [!warning] 三白兵的退化形态
> - **前方受阻**（Advance Block）：第2、3根出现 **长上影线** 或实体变小 → 上涨动力减弱
> - **停顿形态**（Stalled Pattern）：第3根实体显著缩小 → 多方力竭，上涨可能暂停
> 这两种变体不是看涨信号！

## 三只乌鸦 (Three Black Crows) ★★★

```
    ┌──┐
    │▓▓│
    │▓▓│ ┌──┐
    └──┘ │▓▓│
         │▓▓│ ┌──┐
         └──┘ │▓▓│
              │▓▓│
              └──┘
    第1天  第2天  第3天
```

**识别标准：**
1. 三根 **依次下降** 的阴线
2. 每根的 **收盘价接近当天最低价**
3. 每根的 **开盘价在前一根实体范围之内**

| 要素 | 说明 |
|------|------|
| 含义 | 三白兵的 **看跌镜像** |
| 市场心理 | 空方连续三天坚定打压，卖盘势不可挡 |
| 最佳位置 | 上升趋势顶部，尤其是价格处于高位时 |

## 向上跳空二只乌鸦 (Upside Gap Two Crows) ★

```
         ┌──┐
    ┌──┐ │▓▓│ ← 第3天阴线包裹第2天
    │▓▓│ │▓▓│
    └──┘ └──┘
    ═══════ ← 跳空（与第1天阳线之间）
┌──┐
│  │ ← 第1天：上升趋势中的阳线
│  │
└──┘
```

| 要素 | 说明 |
|------|------|
| 结构 | 阳线 + 跳空 + 小阴线 + 大阴线（吞没小阴但仍在跳空上方） |
| 含义 | 多方跳空高开后连续两天收阴 → 上方买压不足 |
| 信号 | 看跌，但较弱，需确认 |

## 三山与三川 ★★

日本版的"三重顶"和"三重底"。

| 形态 | 西方等价物 | 含义 |
|------|-----------|------|
| **三山顶部** (Three Mountains) | 三重顶 | 价格三次试探同一高位未能突破 → **看跌** |
| **三川底部** (Three Rivers) | 三重底 | 价格三次试探同一低位未能跌破 → **看涨** |
| **三尊顶** | 头肩顶 | 三山变体：中间山峰最高 |
| **倒三尊** | 头肩底 | 三川变体：中间谷底最低 |

> [!tip] 东西方互证
> 日本的三山/三川与西方的三重顶/底概念完全对应，但日本方法早了 **数百年**。这是东西方技术分析 **殊途同归** 的典型案例。

## 塔形顶部与塔形底部 ★

```
塔形顶部                    塔形底部
  ┌──┐                         
  │  │ ┌─┐┌─┐ ┌──┐        ┌──┐
  │  │ │ ││ │ │▓▓│        │▓▓│ ┌─┐┌─┐ ┌──┐
  │  │ └─┘└─┘ │▓▓│        │▓▓│ │ ││ │ │  │
  └──┘        │▓▓│        │▓▓│ └─┘└─┘ │  │
              └──┘        └──┘        │  │
                                      └──┘
长阳→小蜡烛→长阴         长阴→小蜡烛→长阳
```

| 要素 | 说明 |
|------|------|
| 塔形顶 | 长阳线 → 若干小蜡烛（高位震荡）→ 长阴线 |
| 塔形底 | 长阴线 → 若干小蜡烛（低位震荡）→ 长阳线 |
| 含义 | 两端的"高塔"（长实体蜡烛）夹住中间犹豫期 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "三根依次上升的阳线，收盘都接近最高价" | **三白兵** —— 强看涨 |
| "三白兵第3根实体明显缩小" | **停顿形态** —— 不再是可靠看涨信号 |
| "三山形态等于西方的什么？" | **三重顶** |
| "三白兵和三只乌鸦的关系？" | **完美镜像** —— 方向相反 |
| "向上跳空二只乌鸦的关键特征？" | 跳空上方连续出现 **两根阴线** |
