# 十字线 (★★★)

#candlestick #single-line #doji #reversal-pattern

## Overview Table (总结)

| 十字线类型 | 形状 | 含义 |
|-----------|------|------|
| **标准十字** | 开盘=收盘，上下影线适中 | 犹豫不决 |
| **长脚十字** | 开盘=收盘，上下影线很长 | 剧烈犹豫，转折信号强 |
| **墓碑十字** | 开盘=收盘=最低价，长上影 | 顶部看跌信号 |
| **蜻蜓十字** | 开盘=收盘=最高价，长下影 | 底部看涨信号 |

## 十字线的核心概念

十字线 (Doji) 是开盘价与收盘价 **相同（或极接近）** 的蜡烛线。实体退化为一条水平线。

```
标准十字      长脚十字      墓碑十字      蜻蜓十字
   │             │            │
   │             │            │
  ─┼─          ──┼──         ─┬─          ─┴─
   │             │                          │
   │             │                          │
```

> [!important] 核心含义
> 十字线 = 多空力量 **完全均衡**。开盘时的力量对比到收盘时没有任何净变化。这是市场 **犹豫不决** 的最强表现。

## 各类十字线详解

### 1. 标准十字线

- 上下影线长度适中
- 含义：市场在平衡状态，等待新催化剂
- 单独出现时信号较弱，需结合趋势背景

### 2. 长脚十字线 (Long-Legged Doji)

| 要素 | 说明 |
|------|------|
| 特征 | 上下影线都很长 |
| 含义 | 多空双方激烈争夺，但最终 **打成平手** |
| 信号强度 | **非常强** —— 市场即将做出方向选择 |
| 典型位置 | 趋势末端（顶部或底部） |

### 3. 墓碑十字线 (Gravestone Doji)

| 要素 | 说明 |
|------|------|
| 特征 | 开盘 = 收盘 = 最低价，仅有长上影线 |
| 含义 | 多方冲高后被 **完全打回原位** |
| 信号 | 强烈的 **看跌** 信号 |
| 最佳位置 | 上升趋势顶部、阻力位附近 |

> [!tip] 记忆法
> **墓碑** 十字 —— 形似墓碑竖立，暗示上方"死亡区域"，多方"埋葬"于此。

### 4. 蜻蜓十字线 (Dragonfly Doji)

| 要素 | 说明 |
|------|------|
| 特征 | 开盘 = 收盘 = 最高价，仅有长下影线 |
| 含义 | 空方打压后被 **完全收复** |
| 信号 | 强烈的 **看涨** 信号 |
| 最佳位置 | 下降趋势底部、支撑位附近 |

> [!tip] 记忆法
> **蜻蜓** 十字 —— 形似蜻蜓振翅，暗示价格从底部"飞起"。本质上是极端版的锤子线。

## 十字线的重要法则

### 法则一：十字线在上升趋势中更有意义

| 场景 | 意义 |
|------|------|
| 上升趋势 → 十字线 | ⚠️ **高度警惕！** 可能预示顶部 |
| 下降趋势 → 十字线 | 信号较弱，需更多确认 |

> [!warning] 关键注意
> 在 **上升趋势** 中，前一根是长阳线后紧跟十字线，这是非常危险的信号，称为 **"十字星"** ——暗示多方力竭。但在 **下降趋势** 中，十字线的看涨反转力度不如在上升趋势中的看跌反转力度大。

### 法则二：十字线需要确认

- 十字线是 **警告信号** 而非 **行动信号**
- 须等待次日蜡烛确认方向
- 与前一根蜡烛线的关系很重要

### 法则三：前一根蜡烛线的影响

| 前一根蜡烛 | 十字线含义 |
|------------|-----------|
| **长阳线** + 十字线 | ⚠️ 极强看跌信号（多方力竭） |
| **长阴线** + 十字线 | 可能看涨，但需确认 |
| **十字线** + 十字线 | 市场高度不确定，大变盘在即 |

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "开盘=收盘，长上影无下影" | **墓碑十字** —— 看跌 |
| "开盘=收盘，长下影无上影" | **蜻蜓十字** —— 看涨 |
| "长阳线后出现十字线" | **高度危险** —— 多方力竭的强看跌信号 |
| "十字线在上升vs下降趋势中哪个更重要？" | **上升趋势中更重要** |
| "十字线的根本含义？" | **多空完全均衡**，犹豫不决 |
