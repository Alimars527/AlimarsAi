# 其他单线形态 (★★)

#candlestick #single-line #reversal-pattern

## Overview Table (总结)

| 形态 | 外观 | 位置 | 信号 |
|------|------|------|------|
| **射击之星** (Shooting Star) | 小实体底部 + 长上影 | 上升趋势顶 | 看跌 |
| **倒锤子线** (Inverted Hammer) | 小实体底部 + 长上影 | 下降趋势底 | 看涨 |
| **光头光脚阳线** (Marubozu↑) | 无影线长阳 | 任意 | 极强看涨 |
| **光头光脚阴线** (Marubozu↓) | 无影线长阴 | 任意 | 极强看跌 |
| **纺锤线** (Spinning Top) | 短实体 + 上下影线 | 任意 | 犹豫 |

## 射击之星 (Shooting Star) ★★★

```
     *
     │  ← 长上影线（≥ 实体 2 倍）
     │
    ┌┴┐
    │ │ ← 小实体（位于价格区间底部）
    └─┘
         ← 无下影线或极短
```

| 要素 | 说明 |
|------|------|
| 出现位置 | **上升趋势顶部** |
| 市场心理 | 多方冲高失败，空方强力打回开盘价附近 |
| 确认 | 须等次日收阴或低开确认 |
| 增强因素 | 出现在阻力位、跳空高开后出现 |

> [!tip] 射击之星 vs 上吊线
> 二者都是看跌信号，但形状不同：射击之星长上影 + 下方短实体；上吊线长下影 + 上方短实体。

## 倒锤子线 (Inverted Hammer) ★★

```
     *
     │  ← 长上影线（≥ 实体 2 倍）
     │
    ┌┴┐
    │ │ ← 小实体（位于价格区间底部）
    └─┘
         ← 无下影线或极短
```

| 要素 | 说明 |
|------|------|
| 出现位置 | **下降趋势底部** |
| 外观 | 与射击之星 **完全相同** |
| 区别 | 出现在底部而非顶部 |
| 市场心理 | 多方尝试上攻（虽被打回），说明买压开始出现 |
| 确认 | **必须确认** —— 次日需收阳或高开 |

> [!warning] 倒锤子线的直觉陷阱
> 许多人觉得长上影线在底部应该是看跌信号（"冲不上去"）。但关键在于：在连续下跌中，多方 **终于有能力** 将价格推高（即使没守住），这本身就是力量转变的信号。

## 光头光脚线 (Marubozu) ★★

完全没有影线的蜡烛线 —— 多方或空方 **绝对控盘**。

| 类型 | 含义 | 特征 |
|------|------|------|
| **光头光脚阳线** | 极强看涨 | 开盘=最低，收盘=最高 |
| **光头光脚阴线** | 极强看跌 | 开盘=最高，收盘=最低 |
| **收盘光头阳线** | 较强看涨 | 有下影但收盘=最高 |
| **开盘光脚阴线** | 较强看跌 | 有上影但开盘=最高 |

> [!tip] 实战含义
> 光头光脚线代表 **全时段单方面控盘**，是最强力的趋势延续/反转信号之一。作为支撑/阻力参考非常可靠。

## 纺锤线 (Spinning Top) ★

```
    │
   ┌┴┐
   │ │ ← 短实体
   └┬┘
    │
```

| 要素 | 说明 |
|------|------|
| 特征 | 短实体 + 上下影线均有（均不很长） |
| 含义 | 多空 **势均力敌**，市场犹豫 |
| 单独使用 | 信号较弱 |
| 组合价值 | 作为其他形态的组成部分很重要（如启明星中间那根） |

## 形态对比总结

| 对比 | 射击之星 | 倒锤子线 | 锤子线 | 上吊线 |
|------|----------|----------|--------|--------|
| 长影线方向 | 上方 | 上方 | 下方 | 下方 |
| 位置 | 顶部 | 底部 | 底部 | 顶部 |
| 信号 | 看跌 | 看涨 | 看涨 | 看跌 |
| 需确认 | 是 | **强烈需要** | 有则更好 | **必须** |

> [!important] 记忆口诀
> **影线指向=战场方向**。长影线指哪个方向，说明那个方向有强力抵抗。在底部长下影=下方有支撑；在顶部长上影=上方有阻力。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "顶部出现小实体+长上影" | **射击之星** |
| "底部出现小实体+长上影" | **倒锤子线**（非射击之星！） |
| "无任何影线的长阳线" | **光头光脚阳线 (Marubozu)** |
| "射击之星和倒锤子线形状有区别吗？" | **没有** —— 区别在出现位置 |
| "纺锤线最重要的用途？" | 作为 **复合形态的组成部分**（如启明星） |
