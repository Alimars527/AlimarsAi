# 锤子线与上吊线 (★★★)

#candlestick #single-line #reversal-pattern

## Overview Table (总结)

| 形态 | 位置 | 含义 | 实体颜色 | 下影线 |
|------|------|------|----------|--------|
| **锤子线** (Hammer) | 下降趋势底部 | 看涨反转 | 不限，阳线更佳 | ≥ 实体 2 倍 |
| **上吊线** (Hanging Man) | 上升趋势顶部 | 看跌反转 | 不限，阴线更佳 | ≥ 实体 2 倍 |

## 形态特征

```
锤子线 / 上吊线：
    ┌─┐
    │ │ ← 小实体（位于价格区间顶部）
    └─┘
     │
     │  ← 长下影线（≥ 实体的 2 倍）
     │
     *  ← 无上影线或极短上影线
```

**识别标准：**
1. 小实体 —— 位于当日价格区间的 **上端**
2. 长下影线 —— 至少为实体长度的 **2 倍**（理想为 2-3 倍）
3. 无上影线或上影线极短
4. 实体颜色不限（但锤子线阳线更强，上吊线阴线更强）

## 锤子线 (Hammer) 详解

| 要素 | 说明 |
|------|------|
| **出现位置** | 下降趋势的底部 |
| **市场心理** | 开盘后空方大幅打压，但多方强力反攻收复大部分失地 |
| **信号** | **看涨** —— 下方有强劲买盘支撑 |
| **确认** | 第二天开盘高于锤子线实体，或收出阳线 |

**增强锤子线可靠性的因素：**
- 下影线越长 → 信号越强
- 出现在支撑位 → 可靠性更高
- 阳线实体 → 比阴线锤子更强
- 伴随放量 → 确认买盘力度

> [!tip] 记忆技巧
> **锤子线 = "锤出底部"** —— 空方用力锤打价格，但价格像弹簧一样反弹回来，暗示底部可能形成。

## 上吊线 (Hanging Man) 详解

| 要素 | 说明 |
|------|------|
| **出现位置** | 上升趋势的顶部 |
| **市场心理** | 多方控盘能力减弱，盘中出现明显回落（即使最终收回） |
| **信号** | **看跌** —— 空方已经有能力打压价格 |
| **确认** | **必须确认！** 第二天低开或收阴线 |

> [!warning] 关键区别
> 上吊线比锤子线 **更需要确认信号**。上吊线虽然收回了失地，但长下影线暴露了多方阵营的脆弱性。如果次日不能继续上涨，则空方将占据优势。

## 锤子线 vs 上吊线 对比

| 对比项 | 锤子线 | 上吊线 |
|--------|--------|--------|
| 形状 | 完全相同 | 完全相同 |
| 区别因素 | **之前的趋势方向** | **之前的趋势方向** |
| 前置趋势 | 下降趋势 | 上升趋势 |
| 含义 | 看涨反转 | 看跌反转 |
| 确认必要性 | 有则更好 | **必须有确认** |
| 理想颜色 | 阳线更佳 | 阴线更佳 |

> [!important] 同一形态，不同含义
> 锤子线和上吊线的外观 **完全一样**——决定其含义的是 **它出现的位置**（趋势背景）。这是蜡烛图分析中"背景决定一切"的经典案例。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "底部出现小实体+长下影线" | **锤子线** —— 看涨反转信号 |
| "顶部出现小实体+长下影线" | **上吊线** —— 看跌反转信号 |
| "锤子线和上吊线形状有什么不同？" | **没有不同** —— 区别在于出现位置 |
| "上吊线为什么更需要确认？" | 因为长下影线表明 **多方仍有反扑能力**，需确认空方真正占优 |
| "下影线至少应该多长？" | **实体长度的 2 倍以上** |
