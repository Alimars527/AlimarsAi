# 反转形态基本概念 (★★★)

#candlestick #reversal-pattern #basics

## Overview Table (总结)

| 概念 | 要点 |
|------|------|
| 反转形态 | 预示当前趋势 **可能改变方向** 的蜡烛图形态 |
| 前提条件 | 必须先有明确的趋势存在 |
| 确认信号 | 反转形态出现后须等待后续蜡烛确认 |
| 反转 ≠ 逆转 | 可能只是从趋势转为横盘，不一定完全反向 |

## 反转形态的基本原则

### 1. 必须先有趋势

- 看涨反转形态 → 必须出现在 **下降趋势** 中
- 看跌反转形态 → 必须出现在 **上升趋势** 中
- **没有趋势就没有反转**

> [!important] 核心规则
> 判断一个反转形态之前，首先确认之前的趋势方向。在横盘整理中出现的"反转形态"意义大打折扣。

### 2. 确认信号

反转形态本身 **不是** 交易信号，而是 **警示信号**。需要后续蜡烛确认：

```
下降趋势中出现锤子线 ──→ 警示信号
  └── 第二天收阳 ─────→ 确认信号 ✓
  └── 第二天继续下跌 ──→ 形态失败 ✗
```

### 3. 反转 vs 调整

| 情况 | 说明 |
|------|------|
| **趋势反转** | 从上升转为下降，或反之 |
| **趋势暂停** | 从趋势转为横盘整理 |
| **关键区别** | 反转形态预示 **方向变化的可能**，不保证完全逆转 |

> [!warning] 常见误区
> 看到反转形态就立刻反向交易是最常见的错误。反转可能只是趋势暂停或小幅调整，而非180°逆转。

### 4. 增强反转信号的因素

| 因素 | 说明 |
|------|------|
| **趋势持续时间** | 趋势越长，反转信号越有力 |
| **支撑/阻力位** | 在关键价位出现的反转形态更可靠 |
| **成交量** | 反转日伴随放量则信号更强 |
| **形态完整性** | 越接近"教科书"标准形态越可靠 |
| **相邻时间框架验证** | 多个时间周期同时出现同方向信号 |

## 反转形态分类

```
反转形态
├── 按蜡烛线数量
│   ├── 单线形态：锤子线、上吊线、十字线、射击之星…
│   ├── 双线形态：吞没、乌云盖顶、刺透、孕线…
│   └── 多线形态：启明星、黄昏星、三白兵、三只乌鸦…
│
└── 按方向
    ├── 看涨反转（底部反转）：锤子线、看涨吞没、启明星…
    └── 看跌反转（顶部反转）：上吊线、看跌吞没、黄昏星…
```

## 顶部反转 vs 底部反转

| 对比 | 顶部反转 | 底部反转 |
|------|----------|----------|
| 先有趋势 | 上升趋势 | 下降趋势 |
| 形态含义 | 多方力竭 | 空方力竭 |
| 速度特点 | **"筑顶"较慢** | **"打底"较快** |
| 原因 | 获利盘有序出场 | 恐慌性抛售后急反弹 |

> [!tip] 华尔街格言
> "行情坐电梯下来，爬楼梯上去。" —— 底部形成速度通常快于顶部。但在某些市场（如加密货币），也可能出现急速崩盘。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "在横盘市场中出现锤子线" | **信号可靠性低**——缺少前置下降趋势 |
| "反转形态 = 立刻反向？" | **不一定**，可能只是转为横盘 |
| "什么因素增强反转可靠性？" | 趋势长度 + 支撑/阻力位 + **成交量确认** |
| "顶部和底部反转哪个更快？" | **底部反转通常更快**（恐慌性抛售后急反弹） |
