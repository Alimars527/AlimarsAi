# 蜡烛图的历史与构造 (★★★)

#candlestick #basics

## Overview Table (总结)

| 要素 | 说明 |
|------|------|
| 起源 | 日本 18 世纪稻米期货市场 |
| 关键人物 | 本间宗久（Munehisa Homma） |
| 核心四价 | 开盘价、最高价、最低价、收盘价 |
| 阳线 | 收盘 > 开盘（通常白色/空心） |
| 阴线 | 收盘 < 开盘（通常黑色/实心） |
| 优势 | 比西方线图更直观、更早发出反转信号 |

## 历史背景

- **17 世纪**：日本建立全球最早的期货交易所 —— 大阪堂岛米会所
- **本间宗久**（1724-1803）：被誉为"蜡烛图之父"，据传积累百次连胜记录
- 日本交易者数百年来一直使用蜡烛图，西方直到 **1990 年代** Steve Nison 引入才广泛认知
- 蜡烛图反映了市场的 **心理博弈** —— 多空力量的视觉表达

> [!tip] 核心思想
> 蜡烛图不仅是价格记录工具，更是市场参与者 **心理状态** 的视觉映射。

## 蜡烛线的构造

```
      │ ← 上影线 (Upper Shadow)
      │
  ┌───┴───┐
  │       │ ← 实体 (Real Body)
  │       │    阳线：开盘 → 收盘（向上）
  │       │    阴线：开盘 → 收盘（向下）
  └───┬───┘
      │
      │ ← 下影线 (Lower Shadow)
```

**四个价格要素：**

| 要素 | 含义 | 位置 |
|------|------|------|
| **开盘价** (Open) | 该时段第一笔成交价 | 阳线=实体底部；阴线=实体顶部 |
| **收盘价** (Close) | 该时段最后一笔成交价 | 阳线=实体顶部；阴线=实体底部 |
| **最高价** (High) | 该时段最高成交价 | 上影线顶端 |
| **最低价** (Low) | 该时段最低成交价 | 下影线底端 |

## 实体与影线的含义

| 特征 | 市场含义 |
|------|----------|
| **长阳线** | 多方强势控盘，买压显著 |
| **长阴线** | 空方强势控盘，卖压显著 |
| **长上影线** | 上方抛压沉重，多方冲高回落 |
| **长下影线** | 下方买盘支撑，空方探底回升 |
| **短实体** | 多空力量均衡，市场犹豫不决 |

## 蜡烛图 vs 西方柱状图

| 对比项 | 蜡烛图 | 西方柱状图 (Bar Chart) |
|--------|--------|------------------------|
| 视觉效果 | 彩色实体，直观 | 简单线条 |
| 信息量 | 实体 + 影线，多空一目了然 | 需仔细辨认 |
| 反转信号 | 1-3 根蜡烛即可识别 | 通常需要更多数据 |
| 心理表达 | 强（实体大小 = 多空力量） | 弱 |

> [!warning] 注意
> 蜡烛图信号 **不能** 替代西方技术分析，二者应 **互相验证** 使用。蜡烛图擅长捕捉反转信号，但不擅长设定价格目标。

## Exam/Test Patterns (考试模式)

| 场景/关键词 | 答案 |
|-------------|------|
| "实体越长意味着什么？" | **多空力量差距越大**，趋势越强 |
| "上影线很长说明什么？" | **上方抛压重**，价格被打回 |
| "蜡烛图最大的优势？" | 比西方技术更早发出 **反转信号** |
| "收盘价是阳线还是阴线的关键？" | 收盘 > 开盘 = **阳线**；反之 = **阴线** |
