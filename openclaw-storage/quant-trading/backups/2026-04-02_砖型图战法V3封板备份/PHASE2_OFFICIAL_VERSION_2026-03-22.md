# Phase 2 Official Version — 2026-03-22

## 一、Phase 2 正式版定位
Phase 2 正式版定位为：
**量化研究增强系统正式版候选结构**。

目标不是继续无边界扩因子，而是把已经验证有效的数据、因子与排序结构固定下来，作为进入 Phase 3（策略定版 + 纸上实盘 / 小资金验证）的基础版本。

## 二、正式版核心结构
### 1. 主框架
- 研究对象：主线趋势-优先样本
- 输出结构：**前筛 -> 二次确认 -> 排序分层**

### 2. 因子正式落点
#### hkhold
- 正式角色：广谱前筛 / 温和排序增强
- 作用：先把整体质量更高的票推到前排
- 原则：不作为主规则硬门槛

#### margin_detail
- 正式角色：行业定向强确认 / 局部高权重增强
- 当前最明确适用场景：元器件高权重强化
- 原则：不作为统一主规则硬门槛

#### moneyflow
- 正式角色：行业差异化辅助过滤 / 辅助解释
- 原则：保留在辅助层，不承担统一主导排序责任

## 三、二次确认三层正式定义
### strong_confirm
- 融资融券确认正向
- 在排序层给予高权重强化

### assist_confirm
- hkhold 前筛通过
- 融资未确认，但承接达到辅助确认标准
- 保留，但不与强确认同级

### front_only
- 只有前筛，没有强确认，也没有足够辅助确认
- 在排序层明确降权

## 四、行业正式结论
### 软件服务
- 当前退出模板最成熟
- 正式保留为核心主战场之一

### 元器件
- 必须结合质量确认
- 正式结构：hkhold 前筛 + margin 强确认 + 排序强化

### 电气设备
- 中等稳定
- 正式保留，但退出侧继续观察

## 五、退出模型正式处理原则
- 止盈不是核心问题
- 当前主要短板：弱势退出 / 时间退出 / 低开止损
- 正式版原则：保留现有成熟退出模板，不再做无休止参数微调
- 后续收敛方式：更多依赖入口质量控制和 Phase 3 实盘验证

## 六、当前完成度判断
- Phase 2 当前整体完成度：约 85%
- 已接近完成，当前剩余工作主要是：
  1. 最后审校与一致性检查
  2. Phase 3 入口准备

## 七、Phase 3 入口说明
当进入 Phase 3 时，工作重点将转为：
1. 使用当前正式版进行纸上实盘 / 小资金验证
2. 连续记录系统输出、实际执行、偏差原因与结果
3. 将“研究有效”推进到“你能稳定使用”

## 八、一句话版本

- margin 负责强确认二次强化
