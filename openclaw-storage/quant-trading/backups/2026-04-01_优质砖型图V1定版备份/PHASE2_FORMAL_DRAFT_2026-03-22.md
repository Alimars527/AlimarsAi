# Phase 2 正式定版草案 — 2026-03-22

## 一、阶段定位
Phase 2 的目标不再是继续扩散式探索，而是将已经验证有效的因子和结构收敛成一个可持续使用的“量化研究增强系统正式版候选方案”。

## 二、当前正式版候选结构
### 1. 主框架
- 以“主线趋势-优先”样本为核心研究对象
- 候选逻辑采用：前筛 -> 二次确认 -> 排序分层

### 2. 因子分层
#### hkhold
- 定位：广谱前筛 / 温和排序增强
- 作用：先把更高质量候选推到前排
- 结论：不作为主规则硬门槛

#### margin_detail
- 定位：行业定向强确认 / 局部高权重增强
- 当前最合适场景：元器件高权重强化
- 结论：不作为统一主规则硬门槛

#### moneyflow
- 定位：行业差异化辅助过滤 / 辅助解释
- 结论：保留，但不承担统一主导排序责任

## 三、二次确认三层结构
### strong_confirm
- 融资融券确认正向
- 排序层高权重强化

### assist_confirm
- hkhold 前筛通过
- 融资未确认，但承接达到辅助确认标准
- 保留，但不等同强确认

### front_only
- 只有前筛，没有强确认，也没有足够辅助确认
- 明确降权

## 四、行业当前结论
### 软件服务
- 当前退出模板最成熟
- 仍作为 Phase 2 正式版的核心主战场之一

### 元器件
- 已确认需要内部区分质量
- 当前最合适接法：hkhold 前筛 + margin 强确认强化

### 电气设备
- 当前中等稳定
- 保留在正式版框架中，但退出和确认逻辑仍需继续复核

## 五、退出模型当前结论
- 止盈不是核心问题
- 核心问题仍在：弱势退出 / 时间退出 / 低开止损段
- 当前定版原则：保留现有成熟退出模板，不再对参数做无休止微调
- 下一阶段应更多依赖入口质量控制减轻退出压力

## 六、当前正式版候选原则
1. 不再继续无边界扩因子
2. 已验证有效的因子按分层放置，不混成单点硬过滤
3. 先保证结构稳定，再进入实盘验证阶段

## 七、Phase 2 完成前还剩的关键动作
1. 审核当前实际 pipeline 输出是否完整体现三层确认结构
2. 把多因子软融合结构进一步固化到长期代码路径
3. 对当前正式版候选方案做最终阶段总结与备份

## 八、Phase 3 预告
当 Phase 2 正式定版后，下一阶段应进入：
- 策略定版
- 纸上实盘 / 小资金验证
- 人机协同执行流程
