# 超短执行模型计划 — 2026-03-23

## 适用范围
- 单针下20
- 砖型图
- 后续其他超短主题战法可复用

## 卖点逻辑
1. 隔日红优先
2. 5% 先止盈，但不是必须全卖
3. 若走势较好：先卖 1/3 ~ 1/2，余仓再看承接
4. 若隔日不涨：直接撤退
5. 不使用 S1/S2/S3 作为超短战法卖点模板

## 买点逻辑（所有战法通用执行层）
1. 默认早盘开盘买
2. 先观察 9:30~9:33
3. 大幅拉升不追
4. 大幅下跌不抄底
5. 等待回踩分时均线再考虑
6. 若 9:33 无合适点，继续观察到 9:37
7. 若仍无合适买点，放弃该标的

## 第一版落地方式
- 先用日线可计算代理特征近似这套执行逻辑
- 等后续有分钟级数据/更细代理时再升级
