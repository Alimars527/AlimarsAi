# 战术体系 V1 — 2026-03-23

## 一、市场总准则
1. 不要频繁交易。
2. 只做主线和主题投资。
3. 不碰白线在黄线下的标的。
4. 放巨量通常用于改变趋势，必须高度警惕。
5. 前30秒疯狂拉升容易诱多，不追。

## 二、常用指标与线
### 1. 白线（知行短期趋势线）
- 公式：`EMA(EMA(C,10),10)`
- 用途：短趋势观察线 / 买点预兆线

### 2. 黄线（知行多空线）
- 公式：`(MA14 + MA28 + MA57 + MA114) / 4`
- 用途：候选资格线 / 大结构生死线

### 3. BBI
- 公式：`(MA3 + MA6 + MA12 + MA24) / 4`
- 用途：持仓管理线 / 放飞与离场线

### 4. 成本线
- 定义：实际买入成本价
- 用途：验证交易是否脱离成本区

## 三、买点体系
### 1. B1（首买点）
#### 定义
强趋势标的在白线之上、黄线之上运行，经历缩量或可控回调后，重新放量突破形成 N 型二次启动的首买点。

#### 核心条件
- DIF > 0
- 白线在黄线上
- 回调后重新转强
- 放量中阳 / 长阳
- 突破颈线 / 平台 / 前高
- 必须是 N 型结构

#### 强化条件
- 收盘不要太弱，最好不是十字星
- J 值越小越好，J≤20 为强化项，但不是绝对必须
- 放量上涨、缩量下跌
- 白线未被有效破坏

### 2. B2（第二买点）
#### 定义
B1 之后经过回调或横盘整理后出现的右侧进攻型买点，买的是主力洗盘结束后的再攻击确定性。

#### 四大硬条件
- 必须出现在 B1 之后的回调或横盘后
- 涨幅 > 4%
- 必须放量，最好倍量柱
- K线形态漂亮，优先光头阳或短上影

#### 四种经典形态
- 平行重炮
- 跃跃欲试
- 灾后重建
- 倍量起爆

## 四、卖点体系（S1/S2/S3）
### S1
- 顶部大风车 / 放量大阴线带长上下影线
- 判断顺序：先看顶部区间 -> 再看巨量 -> 再看阴阳 -> 最后看长上下影
- 含义：高位剧烈分歧，风险预警

### S2
- 放量之后的创新高诱多
- 参考：MACD 顶背离
- 含义：更明确的诱多 / 派发信号

### S3
- 半个月或一个月后回到前高，放天量却卡在下沿上不去
- 含义：套牢盘压制，冲关失败，宜兑现

#### 备注
- S1/S2/S3 是风险信号分级，不是机械卖出强度指令
- 最终减仓 / 放飞 / 拍掉的执行力度，结合是否继续抡、基本面、主力状态等由人工裁决

## 五、白线 / 黄线 / BBI / 成本线动作规则
### 白线
- 回踩白线：买入信号出现的预兆
- 跌破白线：优先级降低，结合 K 线和黄线继续观察
- 反抽白线：从黄线修复到白线，属于趋势修复利好动作

### 黄线
- 在黄线上：标的仍处于可候选区间
- 跌破黄线：可以放弃该标的
- 优先级关系：黄线决定还能不能看，白线决定买点质量

### BBI
- K线连续两根跌破 BBI：直接离场
- K线在 BBI 线上出现两根放量大阳：减仓或放飞

### 成本线
- 若单针下20等超短线战术持有一日后不能脱离成本线，次日应直接离场
- 脱离成本 3% 以上，可考虑放飞一半

## 六、主线战术 vs 主题战术
### 主线战术
- 主要看周 B1
- 以周为单位做长线 / 中线运作
- 偏龙头、核心资产、能拿得住的票

### 主题战术
- 主要看日 B1 / B2
- 以日为单位做短线 / 超短线操作
- 偏概念、轮动、右侧启动、快进快出

### 共同点与差异
- B1 同时适用于主线和主题
- 主线更看周 B1
- 主题更看日 B1、B2
- 若周B1与日B1同时出现（周日共振），优先级调到最高

## 七、三大战术模板
### 1. 少妇战法 1.0
- 定位：主线趋势 / 中短波段 / B1切入
- 关键：择时 -> 选股 -> 等 B1 -> 带套 -> 止盈放飞 -> 跌破 BBI 两天离场
- 主线更看周 B1，主题也可看日 B1

### 2. 深V玩法：单针下20策略
- 定位：主题战术 / 超短线偷袭型
- 指标逻辑：长期资金高位，短期资金被洗至低位
- 重点：只做 N 型上升和 BBI 向上的图形
- 纪律：持有一个交易日必须脱离成本线，否则次日开盘即卖；脱离成本3%以上可酌情放飞一半

### 3. 砖型图超短线战略
- 定位：日级执行战术，不强依赖主线/主题标签
- 条件：股价在黄线上，前一日绿在当日转强红
- 纪律：次日不追高（>4%不买）；收盘前三分钟红砖变绿就走；次日9:33/9:37不拉升就走

## 八、黑话执行映射（摘要）
- 特扑：放量中长阳线，颈线位突破
- 放飞/卤煮：减仓锁利润，剩余利润奔跑
- 拍掉：触发风险信号 / 破位后立即执行离场
- 试训仓/斥候：小仓验证
- 曼城阵容：底仓主力，稳健持有
- 拿拒不动：核心仓位黄线不破，过滤噪音

## 九、当前落地原则
1. 先识别战术适用场景，再决定是否执行。
2. 买点不是见信号就买，仍需结合板块、量能、承接、盘口环境。
3. 卖点识别尽量客观，卖出强度保留人工裁决。
4. 系统后续可做“识别层”，执行强度仍由人工掌舵。
