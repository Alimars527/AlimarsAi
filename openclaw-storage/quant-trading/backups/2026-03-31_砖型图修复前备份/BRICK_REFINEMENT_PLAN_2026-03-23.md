## 第一版约束
1. close >= yellow_line * 0.98
2. close >= white_line * 0.97
3. ma5 >= ma10 或 close >= ma5
4. pct_chg > -3
5. vol >= 近5日均量 * 0.9
6. brick_red_turn / brick_exec_ready 必须发生在非明显破位状态
